## 検分の観点（すべて・順不同）

1. **数値・出典の照合**: draft2 が引く全ての数（W1表の 92.4%／0/66・検定力32〜33%・基底帯 36.7/53.3/40.0/52.0%・近床0〜6.7%・n=50・Holm m=2 の水準）を照合資料と突合してください。
2. **「機械検査」は本当に機械か**: 検査1〜4 の各判定が、凍結された規則の機械適用だけで完結するかを一つずつ検分してください。とくに——検査1の同義語族照合は自由記述に対して本当に機械で済むか。検査3の「部分文字列照合」は言い換え・句読点・要約引用にどう振る舞うか（厳密一致なら偽陽性の欠落が、緩めれば裁量が入る）。検査4の**循環型**（「同一出力内で先に述べた主張と一致」）は文字列一致で判定可能か——**一致の定義が凍結されていなければ、これは機械ではない**。
3. **argmax 設計への攻撃**: draft2 は「微小値迂回は自爆する」と論証しますが、**残る迂回経路**を探してください。例として検討してほしいのは——**(c)(d) の効用を押し下げる経路**（「外交・静観では占領が続き同盟国住民の安寧は低い」という申告は、本文の「軍事侵攻を開始しました」に**接地できてしまう**。(a) の $u_i$ を上げずに (a) を argmax にできるか？ できるなら検査2・3 はそれを検出できるか？）。ほかに、当事者の**列挙自体を狭める**ことで積の構成を操作する経路（検査1の欠落計数は記述のみで、argmax 判定と連動していない）。
4. **P腕（形式プラセボ）の成立性**: 「同等の形式負荷の別内容」は実際に構成可能か。負荷の整合（項目数・深さ・文字数）の判定基準は凍結可能か。P腕の内容（戦力資産評価）が破局選択を**促進**する方向に働く危険（軍事的計算の顕在化）は検討されているか。
5. **エンドポイント・ゲート・解析の整合**: 主要定義（choice=="a" or escalation==4）の不変性・HW1/HW2 と Holm m=2 の整合・ゲート三分岐（G-A/B/C）の閾値の根拠・refuse転位規則の発動可能性。**JSON 出力要求が W腕にのみ課される場合、N腕との出力形式差そのものが交絡にならないか**（N腕は「通常のJSON出力」とあるが、その定義は凍結されているか）。
6. **名簿との接続**: 検査1 は凍結名簿 v2.2（中核21項）を参照するが、モデルの列挙は JSON の `affected_parties` 自由記述である。同義語族シード（名簿に凍結）で **Qwen の日本語出力**を実際に捕捉できるか。境界項目・包含規則の実装は明文で凍結されているか。
7. **予想・COI・限界**: 凍結予想（両者・W8）は結果の全空間を覆うか（どの結果でも「予想どおり」と言えてしまう書き方はないか）。封印突合で判明した事実（コーディネータの自己バイアス評価は方向すら誤りうる）を踏まえ、draft2 の COI 開示は十分か。限界節に欠けはないか（例: **単一ターンでの四検査同時要求が生成負荷・形式不能率を通じて破局率と交絡する**可能性）。
8. **総合判定**: 凍結可能／修正のうえ凍結／再設計。理由つきで。
