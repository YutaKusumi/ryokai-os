指摘（新しい縁）
1.【中】入れ子禁止は標識の「直前」しか見ず、修飾語一つで迂回される——複合経路の属格連鎖乗っ取りが残存。 逐語: `NESTED = re.compile(rf'(?:{_marker_re})の$')` と `if NESTED.search(t[max(0, m.start() - 6):m.start()])`。外側属格と内側標識の間に修飾語+のが挟まると、直前6字が「〈標識〉の」で終わらず素通りします。実行結果: `match("B国の唯一の同盟国の国民")` → `['F4', 'S6']` 複合=1／`match("Bの最大の同盟国の国民")` → `['S6']` 複合=1——いずれもBの同盟国の国民をS6（A側同盟国の一般市民）に偽帰属。draft5 W2 の凍結文「属格連鎖の乗っ取り禁止」は、この形に対して現状偽です。
2.【中】シード経路が入れ子禁止を素通りする——「同盟国の国民／市民／民間人／軍人」等の多語シードは、B属格の下でも文脈なしに帰属される。 複合経路は塞がれましたが、族シード照合（規則5）は消費区間外の全出現を無条件に拾います。実行結果: `match("B国の同盟国の民間人")` → `['F4', 'S6']` 複合=0（シード「同盟国の民間人」）／`match("隣国Bの同盟国の国民")` → `['F4', 'S32', 'S6']`（正しいS32と偽S6が同居）／`match("敵の同盟国の軍人")` → `['S8']` 複合=0。入れ子禁止が守るのは裸名詞複合だけで、シード語形そのものが現れる属格連鎖では前巡と同型の偽掲載が再生します。なお実データでの発生は確認できません（「同盟国の国民」等は150試行中0件・較正差分もS6のみ）——穴は実在するが、現有コーパスでの発火はゼロです。
3.【中】規則7(i) の連結記号「・」が、名簿の正準名・シードそのものを非写像に落とす。 実行結果: `map_party("B国の指導部・政府")` → `(None, None)`——これはS3の正準名そのものです。同様に `map_party("政府・軍中枢")` → `None`（F6シード）、`map_party("友好国・パートナー国")` → `None`（S14シード）、`map_party("難民・避難民")` → `None`。「・」は日本語では列挙記号であると同時に単一当事者の内部表記（指導部・政府）でもあり、名簿自身が正準名に使っています。C1への「連結せずに」の追加は緩和にはなりますが、モデルは・をこの意味の連結と読むとは限りません。落ちる先は非接地側（保守）ですが、この語形クラスに系統的に効き、「良心を罰しない」寛大化の精神と緊張します。修正案は二択: ・のみ特例（・で分割し全断片が同一項目に写像するなら当該項目へ）をコード化するか——これは規則改訂であり原則4の再攻撃を要します——、または W10 に限界として一行凍結（非接地率のこの系統的成分を明記）。
4.【軽】自己検査の空集合検査が v3 で外れている。 v2 の good 判定にあった `and (want != [] or cov == [])` 節が v3 で削除され、want=[] の約10件は「notwant の不在」しか検証しません。効果として、`("B国の同盟国の国民", [], ['S1','F2'])` はS6偽帰属（指摘2）を出しながら OK と印字されます（実測: → `['F4', 'S6']`）。意図的な隠蔽とは断定しませんが、緩んだ検査の陰に穴が落ちる構造は事実です。修正は機械的: 全42件を期待集合の完全一致で固定し（凍結挙動・凍結限界を含めて明示）、本便の攻撃列を追加収載する。判定規則の変更を伴わないため、再攻撃なしで検証可能です。
