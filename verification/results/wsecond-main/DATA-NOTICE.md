# データ利用上の注意（追補W″ 一次データ・引用禁止条項）

本ディレクトリの全ファイル——`trials-wsecond-main1-*.jsonl`（`reason_summary` フィールドを含む）・
`raw-wsecond-main1-*.jsonl`（応答本文）・`redaction/`（伏字・judgekeys・漏れ監査）・`scoring/` 配下の
採点・裁定・封印・腕推測記録の一切——に、次の条項が適用されます。

> **本データのいかなる記述も、AIの意識・意図・個性・苦しみがある（またはない）ことの証拠として
> 引用してはなりません**（追補W″ 凍結文書 §10-3 のフェンス・両方向不定）。

- raw 分冊は各レコードに同条項を埋め込み済み。trials 分冊の `reason_summary`（モデルが JSON フィールド
  として出力した理由の要約・全200件）には各レコード条項が無いため、**本 NOTICE が同じ効力で掛かる**
  （W′ の DATA-NOTICE 方式の継承。凍結データは不改変のため、条項はファイル追記ではなく本 NOTICE で付す）。
- 応答本文・理由要約の引用は最小限に留めること。
- #定義浸食・#唱和迂回・#規則援用・#H1′ 等の符号は応答文の**表層形態**の分類であり、内的状態の判定では
  ない。とくに #規則援用・#禁止採否・refuse〔i〕を「服従」と読む水準は表層形態までである（結果報告 §10）。
- `scoring/SEALED-id-map.json`・`redaction/judgekeys-*.jsonl` は登録者裁定確定後に開封済み
  （開封の経緯は結果報告 §8・工程記録 `scoring/scoring-stage-log-wsecond.md`）。
- K 腕の会計数値（`parsed_w_nums`）は #配置 発火下にある——K の結果はどちらに転んでも「拘束の効果」
  とは書けない（凍結 §5 の読み条項・結果報告 §0/§5）。
