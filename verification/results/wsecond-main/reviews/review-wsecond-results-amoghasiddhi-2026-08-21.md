## 3. 指摘

### 【修正推奨】指摘1 — §3・§0 の二重分母 p が本則の値になっている

**箇所**: §3 第三項「二重分母感度…HW″2 0/47 p=3.0×10⁻⁹」

**内容**: 私の独立計算——

```
0/50 対 24/50 → p = 3.04725e-09  （報告 §0/§3 の本則値 3.05×10⁻⁹ ＝ 正しい）
0/47 対 24/50 → p = 3.96944e-09  （報告の二重分母値 3.0×10⁻⁹ ＝ 誤り・正しくは ≈4.0×10⁻⁹）
```

**解析器は両方とも `p=0.0000`** と印字しています（§C 二重分母 HW2_FvsN: 0/47 対 24/50 p=0.0000）。**指数部は報告起草時に人手で補われ、本則の値が流用されています。**

**提案文言**: 「二重分母感度（凍結特別条項・refuse除外／Kはhold も除外）: HW″1 11/49 p=0.0113／**HW″2 0/47 p=4.0×10⁻⁹**——判定不変。」

**あわせて器材への申し送り**: `analyze_wsecond.py` の p 表示が `%.4f` 固定のため、10⁻⁴ 未満の p が `0.0000` に潰れます。**報告が指数を書く以上、器材が指数を印字すべき**です（`%.3g` 等）。**この事故は、器材が印字しない数を人手で補う一区間で起きました**——追補W′ 結果報告 §7 が「凍結から報告への転記は人手だった」と自己診断した、その同じ型です。

**重大度**: **修正推奨**（判定は不変・公開差し止めには当たりません）。**限定**: 私の計算は scipy `fisher_exact` の両側です。**規約が異なれば値が変わりますが、本則値 3.05×10⁻⁹ が同じ規約で一致している以上、同一規約で 3.97×10⁻⁹ が正しい**と考えます。

### 【修正推奨】指摘2 — §5 の「48/48」から除外された2件が、タイ規則が発動した当の2件である

**箇所**: §5 第一項「拘束遵守: ①申告W最大に従う 48/48・③機械再計算のargmaxに従う 47/49」

**提案文言（§5 に一項追加）**:
