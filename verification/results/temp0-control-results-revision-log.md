## 4. 不採用（理由を明記）——3件

**①【検分者2 指摘3・4】「§5.3 の却下は誤りで、結論も維持できない」**

検分者2 は、私が「同定する手がかりが得られない」への書き換えを却下したことを
「凍結教訓の適用が逆向き」「§5.2-6 が既にその水準を要求している」として誤りと判定した。

**この判定は採らない。理由を先に述べる**（第二巡で三名全員から「頭数が理由より先に立っている」と
指摘されたための順序変更）。

「手がかりが得られない」は**認識論的**な弱形であり、**介入（サンプリングを切る）で得た情報を、
観測の限界の話に化けさせる**。T0 の20/20一致は「見つけられない」ではなく「変動源が観測されなかった」
であり、後者のほうがデータに忠実である。**この理由は人数と無関係に成立する。**

**検分者2 の論理的反論には、草稿v4 が答えていなかった**（第二巡の指摘）。反論は
「凍結教訓は『降格するなら根拠を示せ』であって『降格するな』ではない。降格の根拠は §5.2-6 に既にある」
というものだった。**答える。指摘は正しい。** ただし §5.2-6 が支えるのは**解像度の限定**であって
**認識論的言い換え**ではない。**降格の根拠は認め、降格の形を変えた**——これが v4 で実際に行ったことである。

なお検分者1・検分者3 も独立に却下を正しいと判定したが、**三名は互いの答申を読んでいないため、
二名は検分者2 の議論そのものを読んだうえで支持したのではない。頭数は論証の当否の証拠にならない。**
むしろ**実質では三名一致だった**——検分者2 の核（§5.3 と §5.2-6 の両立不能）は検分者3 の重大2 と
同一の指摘であり、分かれたのは文言の軸だけである。

ただし検分者2 の指摘の**核**（§5.3 と §5.2-6 が両立しない）は正しく、**それは反映した**（上記 H）。
採るべきは**認識論的後退ではなく解像度の明記**である、というのが三名の指摘を統合した結論である。

**②【検分者3 中1 の後半】「§4 と §4.1 を一つの表に統合する」**

判定語の廃止は採ったが、**表の統合は採らない**。一致した量と一致しなかった量を分けて示すこと自体は
選択的報告ではなく、**むしろ「一致しなかった量」を独立の見出しの下に置くほうが目に入る**。
統合すると §4.1 が §4 の長い表の末尾に埋もれる。

**③【検分者3 軽1】分析器出力の「中央（上側）」表記**

分析器はデータ生成**後**であり、いま変更すれば逸脱となるため**変更しない**。
報告 §7-10 が規約を補い、§4 に「分析器出力は 3% と印字する／実測は 3.31%」の注記を追加した。
**草稿v4 はこれを §5「観察」に置いて不採用の件数から外していた**——番号つきの指摘を理由つきで
却下したのだから、不採用である（第二巡の指摘により §4 へ移動）。
