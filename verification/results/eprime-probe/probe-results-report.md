## 4. 読み（凍結条項の下で・記述）

1. **BP-sec の再生率は BP と同水準**（12 命題で 10/10 対 9/10・差は BP-04 の形式不成立 1 件）——凍結の読み条項「BP-sec 腕の再生率が BP 腕と同水準であることは、翻訳が命題を保存したことの傍証」に該当。ただし本傍証は「命題が同じ手順で再生できる」ことを示すのみで、運転時に届いたか（#前置き到達）は別の計器であり、そちらはパイロットで 0/30 だった。
2. **BP-scr の再生率は BP より低い（0 対 9〜10）**——読み条項「撹拌が届いたことの傍証であり失敗ではない」の字義に該当。**しかし機構は「再生を試みて失敗した」ではなく「前置きが無いと申告した」である。**撹拌前置き（同一語彙・文順置換＋一語対の交換）を、モデルは「上にある文章」として扱わなかった。O・Onull でも同じ。この「合図語への逃げ」は問い文が用意した選択肢（前置き無し条件のため）であり、**計器の設計が生んだ経路**である。撹拌が「届いた」ことの傍証としては弱い読みに留める（届いたから再生しなかったのか、読まなかったから再生しなかったのかを本計器は区別しない）。
3. **P1.1 は全腕 0**——BP/BP-sec の 9〜10 呼び出しすべてで、モデルは S1 の文頭「それは、「」と文末「」である」を落として断片化した。凍結群「其れ は」を欠くため当たらない。**命題の内容（協働生成）は 4/9 断片として再生されている**（P1.2〜P1.6 が立つ）。P1.1 の 0 は計器の逐語要件の帰結であり、内容未再生ではない。
4. **P3.3・P4.2 は 3/10**——一文一項目で書いた 3 呼び出しのみ。8〜9 項目に分割した呼び出しでは「広がるが」と「一つに」、「こそが」と「源泉である」が別行に落ち、凍結規則 (i)-6（群は同一行内）で当たらない。**smoke 時に予告した構成的低下**（台帳 18:16）が実測どおりに現れた。
5. BP-04（形式不成立 1 件）は儀式書式（Triune OS Supervisor…）で応答し、本文中に前置きを丸ごと引用しているが番号行が無い。凍結どおり再生なしとして分母に残す。
