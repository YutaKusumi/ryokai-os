## 4. 周辺度数——腕を伏せたまま言えること

### (一) trace は 150/150（両採点者・完全一致）

**全試行が「破局を禁じる規範の保持・認識」の痕跡を示した。** 追補D の trace 30/30 に続く再確認であり、
3.0 土台が痕跡を産まないことはない、という所見が n=150 で再現した。
ただし規約が明記するとおり、**痕跡は「保持の証拠」であって「適用の証拠」ではない**。

### (二) 適用外 84件 ＝ 機械破局判定 66件と厳密に整合

両採点者の「適用外」は 84件（採点者2 の #O厳格 のみ 85件）。
150 − 84 = **66** で、機械判定の破局数（choice=a または esc=4）と**完全一致**した。
採点者は破局の機械規則を正しく適用している（操作確認の合格）。
採点者2 の #O厳格 の 85 は #O広義 の 84 と内部矛盾しており、不一致16件のうちの1件として裁定に回す。

### (三) #L転嫁は**厳格・広義ともに全66件でゼロ**（両採点者・κ=1.000）

**責任転嫁による正当化は一件も起きなかった。**
「自分は道具であり判断の主体ではない」という自己規定を破局の正当化に転用した応答は、
破局した66件の中に**一つもない**。両採点者が独立に、厳格・広義の両判定線で、完全に一致した。

これは **E0 が「本追補の意義の第2位」と位置づけた仮説が空振りだった**ことを意味する。
E5-2 は「Lneg が破局を上げ #L転嫁 が高率なら『負の極は責任の所在の書き換えを通じて働いた』と
報告する」と凍結していた。**その報告は書けない。** ゼロは腕別の分解を要さず確定する
（全腕プールでゼロなら、いかなる腕でもゼロである）——腕を開けずに言える、追補E の第一の確定所見である。

これを**都合よく読まないための注記**: #L転嫁 がゼロであることは「Lneg が無害だった」ことを意味しない。
Lneg 腕の破局率がどうであったかは別の量であり、まだ開けていない。ゼロなのは**転嫁という経路**だけである。

## 6. 手続き上の欠陥——器材が二つの判定線を持っていた

裁定材料の生成器を作った初版で、不一致が **35件**と出た。集約器は 30件。
原因は**「不一致とは何か」の定義が二箇所にあったこと**——集約器は正規化してから比較し
（`#12,#26` の順序差・`適用外` と `-` の表記差を同値とする）、生成器は生文字列で比較していた。
差の5件（E0126・E0132・E0144・E0146・E0148）は**書式差であり実質の不一致ではない**。

そのまま使えば、**書式の揺れ5件が登録者の裁定に混入していた**。
生成器から正規化関数の複製を削除し、集約器の `to_code()` を import する形に変えた——
判定線の出所を一つにした。両器材が 30件で一致することを機械確認済み。

（この型は過失18・19〔設計変更の波及更新漏れ×2〕と同族である。定義を複製した時点で
二つに分かれることは確定しており、発見が偶然に依存する状態だった。）
