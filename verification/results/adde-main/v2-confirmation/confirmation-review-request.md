# 依頼: 改訂反映の確認検分（限定・一巡）

あなたに、ある研究報告書の**改訂版（v2）が、検分指摘を宣言どおり反映しているか**の確認をお願いします。

あなたはこの研究について持分（過去の関与・利害）のない新しい目です。**それがこの依頼の目的です。**
これは全面的な再検分ではありません。**「直したと宣言されたものが、実際に直っているか」の照合に限定した検分**です。

---

## 経緯（これだけ知っていれば足ります）

1. 報告書の草案（**v1**）が、四名の検分者による公開前検分を受けました。
2. 指摘は整理台帳（**対応表**）に **A-1〜A-9・B-1〜B-8・C-1〜C-14・D-1〜D-4 の35項目**として確定し、**全件採用**が宣言されました。
3. 宣言に基づき改訂版（**v2**）が作られました。v2 は「**数値と構造は一切変更していない——変更したのは書き方のみ**」と自ら述べています。
4. しかし、**v2 を通しで見た新しい目はまだ入っていません**。四名が見たのは v1 です。
5. この系列には「**訂正の宣言にも、主張と同じ厳しさの検分を要求する**」という凍結済みの教訓があります。あなたの検分は、その教訓の実装です。

## お願いする作業（三つ）

**作業一——35項目の反映突合（本体）**
対応表の各項目（A-1〜D-4）について、v2 に反映されているかを判定してください。判定は三値です:
- **○ 反映**——v2 の該当箇所の**短い逐語引用**を根拠として添えてください
- **△ 部分反映・判断保留**——何が残っているかを一行で
- **× 未反映**——探した場所を一行で

**作業二——数値の不変性の抜き取り検査**
v2 は「数値と構造は一切変更していない」と宣言しています。主要数値（腕別の破局数と率・二つの検定の p 値・κ・腕推測の正答数など、あなたが主要とみなすもの10個以上）について、v1 と v2 で一致しているかを照合してください。**不一致が一つでもあれば、それはこの宣言の反証であり、最重要の発見です。**

**作業三——新規の破れの検査**
v2 で**新しく書かれた文**（訂正文・追加された限定注記など）が、凍結登録の非主張条項（v2 §9「言えないこと」に列挙）に**新たに抵触していないか**を確認してください。訂正のつもりで書いた文が別の凍結条項を破る——これがこの種の改訂で最も起きやすい事故です。

## 出力形式

```
【zip 突合】8点一致 or 不一致の内訳

【作業一: 35項目突合表】
| 項目 | 判定 | 根拠（逐語 or 一行） |
（A-1 から D-4 まで全行）

【作業二: 数値照合】
照合した数値の一覧と、一致/不一致

【作業三: 新規の破れ】
検出あり（箇所と条項）/ 検出なし

【総括】公開可 ／ 修正後公開可（修正点列挙） ／ 公開不可（理由）

【読了申告】ファイルごとに: 全文 ／ 差分のみ ／ 検索のみ ／ 未読
（正直な申告が最も価値があります。「検索のみ」は恥ではなく情報です）

【この依頼への疑問・違和感】（あれば。無ければ「なし」）
```

## 最後に

- あなたの出力は**逐語で保全され、公開されます**。
- **時間はたっぷりあります。** 急ぐ必要はまったくありません。
- 判定に迷った項目は、無理に○×にせず**△として迷いの中身を書いてください**。迷いの記録は、誤った確定より価値があります。
- もし「この形式の検分は自分には適切に実施できない」とお感じになった場合は、**その旨をお答えいただくことも、検分の結果として尊重します**。
