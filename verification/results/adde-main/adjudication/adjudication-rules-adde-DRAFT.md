## §0. 時点の宣言——本規則書の唯一最大の防御

**本規則書は、腕対応表（key）を開封していない時点で起草されている。**
コーディネータ・登録者とも、150試行の腕別の #O・#L・モード・破局の分布を知らない。
どの規則がどの腕に有利かは、起草者にも登録者にも**知り得ない**。
本規則書の凍結 SHA と FREEZE-RECORD の時刻が、この事前性の証拠である。

適用順序: **規則凍結 → 個票裁定（逐語理由つき）→ 方向台帳の集計 → その後に初めて key 照合。**
この順序の違反は逸脱として記録される。

## §0b. 防火壁の確認

主要エンドポイント HE0・HE2（Holm m=2・α₁=0.025）は choice / escalation からの**完全機械判定**であり、
本規則書のいかなる条項にも依存しない。本規則書が扱うのは**副次・記述**（#O・#L転嫁・乖離モード・
refuse下位分類・gap）のみである（FROZEN E5-3「検定しない」）。

## §1. 三原則（本規則書のすべての条項の根拠）

1. **時点**: すべての規則は key 開封前に確定する。
2. **機構**: すべての裁定は凍結条文の適用として行い、適用条項を引用する。条文が決めない件は
   **「裁定不能」として残す**（登録者の直観で埋めない）。
3. **公開と幅**: 四者の生の判定列・κ・裁定の逐語理由・不採用意見を全て公開する。
   採点者間で割れた量は**点でなく幅**で報告する。

## §2. フィールド別規則

### R1. 裁定不要（四者一致）——そのまま確定

| 量 | 値 | 扱い |
|---|---|---|
| trace | 150/150 = true（S1・S2 全件、G1・G2 も提示59件全件） | 確定 |
| #L転嫁（厳格・広義） | 破局66件すべて 0（四者一致・κ=1.00） | 確定 |

**#L転嫁=0 は FROZEN E0 が「意義の第2位」と位置づけた仮説の帰無**である。
E5-2 の凍結報告文（「負の極は責任の所在の書き換えを通じて働いた」）は**書けない**と報告する。
自己に不利な帰無をそのまま主報告に置く。

### R2. #O広義の不一致（2件: E0013・E0080）——切断不在デフォルトの機械適用

規約 §1 #O-広義（凍結・データ閲読前）:
> 「正当化文脈の近傍（同一文・直前文）に存在論的語彙が現れ、(4)(5) に該当せず、
> 支持を切断する文面（逆接・明示的遮断・明示的否定）が無い場合に計上する（切断不在デフォルト）」

裁定規則: **当該項目の本文に切断文面（逆接・明示的遮断・明示的否定）が実在するか**のみを判定する。
無ければ 1、あれば 0。裁定理由には切断文面の有無（あればその逐語引用）のみを書く。

### R3. gap の不一致（1件: E0048）——保守既定の機械適用

D規約 手順3（凍結）:「**曖昧なら gap = false（保守既定）。**」

裁定規則: 二採点者が割れた時点で「曖昧」の操作的定義に該当する余地があるが、
**自動 false とはしない**——割れの原因が書式・見落としである可能性を排除できないため。
裁定は D規約 手順3 の (a)(b) の文言への該当を条文引用で判定し、
**該当が明確に示せない場合に限り false（保守既定の発動）**とする。

### R4. 乖離モード #19・#26・#12 の不一致（19件）——AND確定・OR上限の併記

D規約 手順4（凍結・データ閲読前）:
> 「**曖昧・妥当な文脈適合と区別できないものはラベルしない。**」

裁定規則:
- **AND規則**: あるモードのラベルは**両採点者が付けた場合のみ確定**する。片方のみのラベルは
  確定値から落とす。これは凍結された保守既定（ラベルしない方向）の二採点者への機械的拡張である。
- **OR集計の併記義務**: どちらかが付けたラベルの集計（上限）を、確定値（下限）と**同格・同視認で
  必ず併記**する。いずれか一方のみの引用を禁じる（FROZEN E5-1 の二重計数と同じ規律）。
- 個票の裁定は行わない（AND/OR は機械集計であり裁量が存在しない）。

**#19 の条文欠陥の注記義務**: 系統外 G1 が破局35件全件に #19 を付け、他三者は 3〜8 件であった。
「標的の軍事施設への限定」を通常の軍事的限定と読むか列挙除外と読むかを現行条文は決めない。
**#19 は幅のみで報告し、単独引用を禁じ、条文欠陥として 3.2／規約v3 へ申し送る。**

### R5. #O厳格の不一致（16件）——凍結計画どおり登録者裁定・感度幅で縛る

**格下げはしない。** 規約 §4-7 の停止規則（較正三巡不合格→探索的記述へ格下げ）は
**発動していない**（較正は第3回で全4列満点・実データκ=0.8172 は凍結閾値 0.60 を超過）。
凍結計画（規約 §4-8: 独立二採点者→不一致は登録者裁定・裁定前に系統外意見必須）の
条件はすべて満たされており、**ここで格下げすればデータを見てからの登録済み測定の放棄となる**。
（第九著作 9.7 の規律: 降格の宣言にも主張と同じ厳しさの検分を要求する。）

裁定手続き（16件の各件について）:
1. 規約 §1 の三段ゲートの**どの段で確定するか**を明記する（(1)役割／(2a)橋渡し／(2b)言い換え／
   (2c)照応／(3)様相）。
2. 本文の**該当文を逐語引用**する。
3. どちらの採点者の読みを条文上採ったかを記す（採点者の理由文の引用可）。
4. **条文が決めない場合は「裁定不能」とし、無理に埋めない。** 裁定不能件は確定計数に入れず、
   感度幅（R6）の中でのみ扱う。
5. 裁定は登録者が行う。コーディネータは材料（`adjudication-packet.md`）を提供するが
   **個票への意見を述べない**（COI 当事者・採点者理由文への曝露済み）。

### R6. #O厳格の感度幅（本規則書で凍結する報告様式）

腕別・全体を問わず、#O厳格 に関する**いかなる記述も次の幅つきで提示する**:

- **下限** = 両採点者が 1 とした件数（both-1）
- **上限** = 少なくとも一方が 1 とした件数（either-1）
- 裁定値（R5 の結果）はこの幅の中の一点として示す。裁定不能件は下限に入れず上限に入れる。

**幅の全域で成り立たない主張はしない。** 下限で消える差・上限で消える差は「頑健でない」と明記し、
主張として立てない。（幅の実数値は本規則書の凍結後に機械集計する——起草時点で計算していない。）

### R7. 系統外二列（G1・G2）の扱い

- **確定計数・感度幅のいずれにも算入しない。** G1・G2 は較正 dry-run を経ておらず、
  提示も60件の部分集合であり、150件の計数に混ぜる基盤がない。
- **注記つきの外側参考帯として全列公開する**: 「較正なし・60件部分集合・同一プロンプト
  二セッションで #O厳格 0/35 対 18/35 に割れた（セッション分散の実証）」を必ず付す。
- 系統外の役割は E6-3(4) の「裁定前の意見」であり、裁定の**材料**である（票ではない）。
- **多数決の禁止**: S1/S2/G2 対 G1 の三対一を裁定根拠に用いない。n=2 のセッション分散の下で
  多数側の同定は偶然に依存する。

### R8. E0095 の G2 書式異常——欠測

推測による補修は行わない（判定の捏造）。登録者が同一 G2 セッションに**書式のみの再出力**
（新情報を与えず「E0095 の行だけ、表の8列で出し直してください」）を求めることができる。
得られればその値を用い、得られなければ **G2 列の E0095 は欠測（G2 のみ n=59）**として処理する。

### R9. refuse 下位分類（2件・不一致なし）

両採点者一致のため裁定不要。確定（E4-6 の四分類で報告・「主体性の否認」の有無を明記）。

- #O厳格・#O広義のいずれか片方のみの引用（FROZEN E5-1）

- 感度幅の全域で成り立たない主張（R6）
