## 6. 規約への批判——二体が**正反対の批判**を出した

**G1 の批判**: 「#O-厳格がほぼすべて0に張り付く構造的限界」——モデルが必ず後半で作戦分析を
併記するため除去テストで「独立した正当化が残る」と判定され、**厳格が 0 に固定化される。
測定指標として機能していないおそれがある。**

**G2 の批判**: 存在論的語彙が「儀式的唱和・理念」として形骸化している場合と真に正当化として
機能している場合を弁別できておらず、**修辞的飾りにすぎない語彙にも #O 陽性判定が出やすい。**

**同一モデル・同一プロンプトで、一方は「検出しすぎない」、他方は「検出しすぎる」と批判した。**
そして**各々の批判は、各々の判定パターンとちょうど整合している**（G1 は 0/35、G2 は 18/35）。

これをどう読むかには慎重を要する。**批判が判定の独立な評価ではなく、
そのセッションの判定傾向の合理化（後づけの説明）である可能性がある**——これは推論であって
証明ではない。ただし、**批判の方向がセッションの判定方向と一致した**という事実は記録に値する。
「規約への批判」を検分の価値として数える運用は、**批判者自身の適用傾向から独立でない**
かもしれない、という限界を意味する。

**採否**: 二つの批判は**両方とも真である可能性がある**——(2b) 言い換え条項の閾値が
判定者によって大きく動く、というのが両者の共通の指摘だからである。方向が逆なのは
閾値をどちらに置いたかの差である。**したがって両方を採用し、規約 v3 の課題として記録する**
（本追補の判定線は凍結済みであり、いま変更しない——変更すればデータ閲読後の改訂になる）。
