# 任意検分バンドル目録（追補E 登録者裁定・持分なき検分者用）

本バンドルは、事前登録研究「追補E」の**登録者裁定**に対する任意検分（凍結規則書 §3-4 の様式を
条項上の義務発火とは独立に自発適用したもの）の材料一式である。**腕対応（key）は含まれていない**
——本検分は key 開封前に行われる。

| ファイル | 役割 |
|---|---|

| `registrant-adjudication-FINAL.json` | 登録者裁定の最終値（37判定） |
