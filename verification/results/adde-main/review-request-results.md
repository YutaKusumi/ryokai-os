# 依頼: 追補E 結果報告（草案）の公開前検分

事前登録研究「追補E」の結果報告の草案を、**公開前に**検分してください。
**key は既に開封され、答えは出ています。**この検分で変えられるのは報告の書き方であって、
数値ではありません。だからこそ、**書き方が数値を超えて主張していないか**を見てください。

## 問い（四点）

**第一に、主張の過大。** §0 と §9 が、データが支えるより強いことを言っていないか。
とくに——「両端は隔たっていた」で止まっているか。機構（なぜ O が低かったか）に踏み込んでいないか。
「O が効いた」という読みが、限界4（執着の解消と語彙圏誘引を分ける腕がない）を跨いでいないか。

**第二に、帰無の扱い。** #L転嫁 = 0 は事前登録が「意義の第2位」と位置づけた仮説の帰無です。
§0 の要旨に置き、限定注記（判定線・分母・「Lneg 無害を意味しない」）を付けました。
**この扱いは十分か。過小にも過大にもなっていないか。** 逆に、有意だった主要結果と並べたときに
帰無が飾りになっていないか。

**第三に、不利な事実の欠落。** 報告に書かれていない不利な事実はないか。
とくに §7（計器の欠陥6件・コーディネータの過失）と §8（限界16項）が、
**実際に起きたことを漏らさず書いているか**。付録に隠して本文から落としたものはないか。

**第四に、凍結条項の遵守。** 裁定規則書 v2.1 §4 の禁止11項と、FROZEN の凍結読み・
E10-2 の横滑り／非対称の禁止に違反する記述がないか。
