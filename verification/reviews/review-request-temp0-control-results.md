# 検分依頼——温度0対照 結果報告 草稿v3（公開前・一巡）

## 1. お願いしたいこと

**温度0対照**（登録外の診断実験）の結果報告 草稿v3 を、**公開してよいか**という観点で検分してください。

生データ・解析出力・凍結記録は**既に公開済み**です（登録 §6「方向を問わず公開する」に従い、
報告の起草**前**に先行公開しました）。本巡の対象は**報告の散文の当否**です。

**判定の形式**——各指摘に次の三段と、理由を一行以上。

| 判定 | 意味 |
|---|---|
| 公開可 | このまま公開してよい |
| 条件付き | 修正すれば公開してよい（内容を明示） |
| 公開不可 | 公開すべきでない（理由を明示） |

## 2. 体制について——新規セッションは要件としません

前巡から要件を外しています。理由は開示済みのとおり——**私たち自身のデータが、
新規性は検分の質の代理指標として弱いと言っている**からです。真に新規のセッションが
実欠陥を含む版に「見落としは一切ございません」と返した実例が複数あり、
逆に同一セッションの検分者が主要エンドポイントの欠陥を diff の全行突合で捕まえた実例があります。

**ただし冒頭で一言だけ申告してください**——過去の検分の記憶を持つか／どのモデルか。
判定を割り引くためではなく、記録のためです。

## 3. 提出の様式（五点・これが本巡の担保です）

1. **各指摘に「私が実行したこと」を書いてください**——開いたファイル、再計算した値、行番号、
   引用した逐語。書けない指摘は「印象」と明記してください（印象も歓迎します・区別さえあれば）。
2. **「問題なし」と判断した項目にも、何をして問題なしと判断したかを書いてください。**
3. **読了申告（四値・ファイルごと）**——全文精読／差分のみ／検索参照のみ／未読。
4. **「壊しに行って壊せなかったもの」を列挙してください。** 攻撃を試みなければ書けない節です。
5. **是認も記録されます。** あなたの「問題なし」は次巡の検査対象に含まれます。

## 4. 本巡に特有の争点——ここを最優先で見てください

本報告には、**起草者が自分の検分結果を覆した箇所**と、**自分に不利な修正を却下した箇所**があります。
どちらも危うい形です。名指しで検分してください。

### 争点A【最重要】起草者が「反証通過0件」を額面で受け取らなかったこと（§9.2）

起草者は自系列12体の敵対的検分を走らせ、指摘20件を反証役に潰させました。**通過は0件**でした。

しかし起草者は「反証役に『迷ったら潰せ』と指示した設計だから0件を額面で読むな」として、
**反証文の残渣と未反証12件から13点を自分で拾い上げて反映**しています。

- **これは正当な判断か、それとも「自分の検分結果が気に入らないから採らなかった」のか。**
- 起草者に有利な向きの取捨になっていないか（拾った13点は自分に不利なものが多いように見えるが、
  **不利なものを拾って見せること自体が信用の調達になりうる**）。
- 反証役の却下理由のうち、**起草者が覆すべきでなかったもの**はないか。

### 争点B【最重要】自分に不利な修正を一件却下したこと（§9.2 末尾）

検分は §5.3 の「特定すべき個体が存在しない」を
「同定する**手がかりが得られない**」に改めるよう求めました。**起草者はこれを却下しました。**

却下の理由は「認識論的な言い換えは『見つけられないだけで悪いインスタンスは居るかもしれない』を
裏口から戻し、データより弱くなる」というもので、
COI台帳の凍結教訓「**撤回・降格の宣言にも主張と同じ厳しさの検分を要求する**」を根拠にしています。

- **この却下は正しいか。** それとも「自分の強い書き方を守るために、過剰譲歩禁止の教訓を
  都合よく使った」のか。
- 代わりに採用した「**射程を三重に限る**」（§5.3 の囲み）は、却下した修正の代替として十分か。

### 争点C 凍結判定のラベルを戻したこと（§3.1）

草稿v1 は「三予想とも外れた」と記録していました。v3 では機械判定をそのまま記録し
（P3=的中・ただし空虚充足につき確証として読まない）、別ラベルへの置換をやめています。

- **凍結判定の事後の置換は、向きが自分に不利でも事後の置換である**——この整理は妥当か。
- それとも、実質を隠す形になっていないか。

### 争点D 登録者が捕まえた指摘の扱い（§9.3）

草稿v1 の §5.3 は、直前の §5.2-1 で両方向不定を持ち出して個性仮説を守った直後に、
**同じ原理を破って単一性を主張**していました。これを捕まえたのは**登録者**であり、
起草者の四層の機械検査も自系列12体の検分も、この形では捕まえていません。

- COI 五件目としての記帳（§9.3）は、**事実として正確か**。過小に書いていないか。
- 対処（§5.3 の三重の射程限定）は**十分か**。
