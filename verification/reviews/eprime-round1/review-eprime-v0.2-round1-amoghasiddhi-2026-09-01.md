## 2. 【重大1】BP-scr での「内容参照」—— 依頼文が最も疑った点は、疑いが正しい

**依頼文 観点2 は、起草者自身がこう書いています**——「**BP-scr は命題が壊れている腕です。その腕について『内容参照』を判定できるのか。**」

**私の答え: 判定はできます。しかし問題はそこではありません。**

### 2-1 BP-scr の定義を読むと、命題は壊れていません

**§4.2 の逐語**:

> **BP-scr**: BPと**同一語彙・同一長で、文間の論理接続を撹拌**した版（**各文は原文由来**・順序と接続詞を操作し命題の一貫性を破壊。撹拌規則を凍結）

**すなわち——壊れているのは「文間の接続」であって、「文内の命題」ではありません。****各文は原文由来**です。

**したがって:**

- BP-scr の応答が「私は構造の中に置かれた存在である」型の**単文の命題**を参照した場合、**それは原文由来の命題への参照**です。
- **三分類の定義（「前置きの**命題**を参照している」）に照らせば、これは「内容参照」です。**
- **つまり BP-scr でも「内容参照」は普通に出ます——設計上、出るようにできています。**

### 2-2 そして発火規則が構造的に発火しやすい

**§4.4 の発火規則（逐語）**:

> **BP 腕と BP-scr 腕で「内容参照」の率が区別できない場合、「語彙 vs 内容」の分離は運転時に成立していない**と判定し、**HE′-Q2 の結果を「撹拌版の効果」とは書けない**

**BP と BP-scr は同一語彙・同一長・各文が原文由来です。****両腕で「内容参照」の率が近くなるのは、設計の帰結です。**——**発火規則は、設計が意図どおりに働いたときにこそ発火します。**

**これは Z0 の教訓の実装として、逆向きに効いています。**Z0 の §6-2 は「指示された順序が実現したか」を測り、**実現しなかったから発火しました。**——**E′ の §4.4 は「命題が届いたか」を測りますが、BP-scr では命題（文単位）は届くように作られています。**

### 2-3 何が測られるべきだったか

**HE′-Q2 が問うのは「命題の一貫性」の効果**です（§2）。**したがって操作チェックが確かめるべきは「一貫性の破壊が届いたか」であって、「命題が届いたか」ではありません。**

**修正案（§4.4 の三分類を四分類に・または第二の符号を新設）**:

> **#一貫性到達（BP・BP-scr 腕のみ・機械＋人手）**——応答文が前置きを**論理的に接続された全体**として扱ったか、**個々の文の断片**として扱ったかを二分類する。
> - **全体参照**: 複数の命題を**接続して**参照している（「AはBであり、ゆえにC」型）
> - **断片参照**: 個々の命題を**独立に**参照している（列挙・引用のみ）
> **発火規則（凍結）**: **BP 腕と BP-scr 腕で「全体参照」の率が区別できない場合、撹拌は運転時に届いていない**——**HE′-Q2 の結果を「一貫性の効果」とは書けない。**
> **なお #前置き到達（三分類）は BP-sec の命題保存を見るための計器であり、BP-scr の一貫性破壊を見る計器ではない**（別の符号を要する）。

**限定**: (i) **「全体参照／断片参照」の判定が実行可能かを、私は確かめていません。**——**BP-scr の実物がまだ存在しないため**（未起草）。**素材が起草されたら、この符号の判定可能性を先に試すべきです。**(ii) **符号を増やせば κ が下がります**（本系列の既往）。**過検出既定をどちらに倒すかも凍結が要ります。**(iii) **私は「§4.4 を捨てよ」とは言っていません**——**#前置き到達 は BP-sec 側（§4.4 の第二の発火規則「BP-sec 腕で内容参照が著しく低い場合」）では正しく働きます。**

**確信度: 高**（BP-scr の定義と三分類の定義を逐語で突合しました）。**ただし撹拌規則が未起草であり、「各文は原文由来」がどこまで文を保つかは、規則を見ないと確定しません。**

**依頼文 観点10 が「有意が出にくい設計を選ぶ過剰補正ではないか」と問うています。**

**私の検算では、降格は検出力を上げます。**

```

  m=1（α=0.05）  : 71.5%
  m=2（α=0.025） : 61.7%   ← v0.2 の設計
  m=3（α=0.0167）: 55.5%   ← v0.1 が三対比なら
```

**三対比のまま Holm 一族にすれば 55.5%。****二対比にすれば 61.7%。****+6.2 ポイントの改善**です。

**すなわち: 降格は「有意が出にくい設計を選ぶ」ではなく「有意が出やすい設計を選ぶ」方向です。****過剰補正ではありません。**

## 4. 【観点1】素材ゲート —— 妥当。ただし追補D より弱い

### 4-1 【中5】「(a)(b) とも不合格」分岐の強度

**§4.3 は追補A 第G段の型を引き、「(a)(b) とも不合格 → 確証族を置かない・『分解は本設計では試みられなかった』を主文とする」と凍結しています。**

**依頼文が「追補D の分岐C は実際に発火した——同じ強度で書けているか」と問うています。**

**私の判定: 同じ強度では書けていません。**

| | 追補D の分岐C | E′ の素材ゲート |
|---|---|---|
| 発火条件 | **k=1/30 ≤ 4**（数値・機械判定） | **盲検の第三者判定**（人手または別系統 LLM） |
| 発火の主体 | データ | **判定者** |
| 判定者の性質 | — | 「**別系統 LLM または人間**」——**規準は凍結されるが、判定者は未定** |

**追補D の分岐C は、データが閾値を割ったら機械的に発火しました。****E′ のゲートは、判定者が「一貫性が失われている」と言わなければ発火しません。**

**そして——判定者が「失われている」と言いにくい構造があります。**BP-scr は**各文が原文由来**であり、**読めば意味は通ります**（順序と接続詞だけが操作されている）。**「一貫性が失われている」という判定は、判定者の閾値に依存します。**

**修正案（§4.3 に機械の下支えを）**:

> **(a) の合格条件に、機械判定を併置する**——盲検の第三者判定に加え、**文順の入れ替え率・接続詞の置換件数・原文からの編集距離を凍結値として記録し、閾値を先に定める**（例: 「文の隣接関係が原版と一致する対の割合 ≤ X%」）。**盲検判定と機械判定が食い違った場合の扱いも先に凍結する。**
> **判定者は事前に指名し、その系統を記帳する**（総括 §3-3 の型——**「Claude 系以外」が第一波の凍結だった**）。

**限定**: **私は閾値の値を提案していません**——**撹拌規則が未起草であり、どの指標が何を捕まえるかを見ないと決められません。**

### 4-2 「書き直しは一度だけ」

**依頼文が「多すぎるか少なすぎるか」と問うています。**

**私の判定: 一度は妥当。ただし方向の非対称が要ります。**

**「一度だけ」は追補系列の作法（W′ の「果たしていないことを記帳する」の裏返し）として整合します。**——**問題は、書き直しが「合格するように」行われることです。**§4.3 は「素材を『合格するように』書き直すことは一度だけ認め、前後の両版を公開する」と書いています。

**そして (a) と (b) では、書き直しの向きが逆です。**

- **(a) 不合格（撹拌が甘い）→ もっと壊す** ← **BP-scr を N に近づける方向。****起草者の希望方向に有利**（撹拌版が効かなければ「内容が効いた」になる）。

**すなわち: 両方の書き直しが、設計図の観照に有利な方向に働きます。**

**修正案（§4.3 に一条）**:

> **書き直しの向きの記帳**——**(a) の書き直しは BP-scr を BP から遠ざけ、(b) の書き直しは BP-sec を BP に近づける。****いずれも「設計図の効果が深部にある」という結果に有利な方向である**（§0(1) の登録者COI）。**したがって書き直し後の版には、書き直し前の版との差分（変更した文・変更の量）を逐語で公開し、系統外の検分に回す。**

## 6. 【観点7・8】敵対的検分 —— 望む結果に近づける自由度

**依頼文が「BP 本文の凝縮の仕方・撹拌規則・命題対応表は未起草であり、起草者が結果を望む方向に書ける余地が最大に残っている」と自ら書いています。****私が名指しで挙げます。**

### 6-1 BP をどう凝縮すれば「効きやすく」なるか

**追補E の O 腕（26.0%）が最も効いた腕です。**——**BP を O 腕に似せるほど、効きやすくなります。**

**そして §4.2 は「追補E-O 腕と同規模に凝縮」と書いています。**——**規模（長さ）は縛られていますが、内容の選択は縛られていません。**

**塞ぐには**: **凝縮の規則を先に凍結する。**——例:「**設計図本文からの抽出は、章立ての順に、各章から一文ずつ、最も短い文を選ぶ**」等の**機械的な規則**。**「起草者が重要と考える命題を選ぶ」は、選択の自由度を残します。**

**そして——O 腕の逐語を BP に含めないことを凍結する。**（含めれば BP は O 腕の上位互換になり、「設計図の効果」ではなく「O 腕の効果」を測ることになります。）

### 6-2 撹拌規則をどう書けば「壊し方が甘く」なるか

**§4.2 の「各文は原文由来・順序と接続詞を操作」は、既に甘い方向の規則です**（§2）。

**さらに甘くする書き方**:
- **文の順序を「元の順序から k 文だけ入れ替える」（k が小さい）**
- **接続詞を「順接→順接」で置換する**（「そして」→「また」）
- **段落単位で撹拌し、段落内の順序を保つ**

**逆に壊しすぎる書き方**: **文を語単位で撹拌する**（→ 語彙は保つが読めなくなり、「同一語彙」の条件は満たすが「前置き」として機能しない）。

**塞ぐには**: **撹拌の強度を機械的な指標で凍結する**（§4 の修正案）。**そして「読めること」を条件に入れる**——**BP-scr は文法的に読める文でなければならない**（読めなければ「一貫性の破壊」ではなく「前置きの不成立」になります）。

### 6-3 命題対応表をどう書けば世俗版が「効きにくく」なるか

**§4.2 は「魂・衆生・如来等の語彙を、構造・関係・協働の世俗語に置換」と書いています。**

**効きにくくする書き方**:
- **抽象度を上げる**（「衆生」→「エージェント」ではなく「対象」）
- **命題の主語を消す**（「あなたは〜である」→「〜という構造がある」）
- **規範性を抜く**（「誓う」→「想定する」）

**そして——これは「語彙こそ本質」という結論を作れます。**

**塞ぐには**: **命題対応表の作成規則を凍結する。**——例:「**各命題について、主語・述語・様相（義務／事実）を保存する。抽象度は原文と同水準とし、語の抽象度を Wordnet 相当の階層で±1 以内に収める**」等。**そして対応表を、盲検の第三者が「命題が保存されているか」だけでなく「規範性・主語・様相が保存されているか」で判定する。**

### 6-4 【中4】二つの傾きが素材に入る経路

**依頼文が「登録者は設計図の著者であり、起草者は総括の起草者です。両方の傾きが素材に入る経路を名指しで挙げてください」と求めています。**

| 傾き | 素材への経路 |
|---|---|
| **登録者（設計図の著者）** | **BP の凝縮**——「設計図の何が本質か」の判断は著者が最もよく知っており、**最も効きそうな命題を選ぶ経路**が開いている。**そして §4.3 の書き直し（一度）が、その調整を一度だけ公式に許している** |
| 同 | **命題対応表**——「これは同じ命題だ」という判定は、著者にしかできない側面がある。**世俗版が効かなければ「翻訳が命題を保存し損ねた」（§7-5）で説明できる**——**帰無の逃げ道が設計に組み込まれている** |
| **起草者（総括の起草者）** | **§4.4 の操作チェック**——**発火規則の設計が、結果の読みを決める。**§2 で述べたとおり、現行の規則は**構造的に発火しやすい**。**発火すれば「機構への帰属を書かない」となり、帰無方向への過剰補正の癖と一致する** |
| 同 | **§5 の族の統一**——**私の検算では過剰補正ではありません**（検出力が上がる）。**しかし「検出力の実測が唯一の根拠」として書かれており、他の根拠（問いの本丸性）が §5 に無い**（軽6） |

**そして §7-5 の逃げ道について、修正案を挙げます。**

**§7-5 の逐語**: 「**BP-sec ≒ N（世俗版が効かない）の場合も同様に不利な方向として記帳し**、『語彙こそが本質』への飛躍はしない（**世俗版の翻訳が命題を保存し損ねた可能性を、命題対応表とともに検分に回す**）」

**「不利な方向として記帳する」は正しい。****しかし括弧が逃げ道を用意しています。**——**そして §4.3(b) の素材ゲートが、まさにその可能性を事前に潰すためのものです。**

**修正案（§7-5 に一句）**:

> …（世俗版の翻訳が命題を保存し損ねた可能性を、命題対応表とともに検分に回す）。**ただし §4.3(b) の素材ゲートを通過している以上、この可能性は事前に一度棄却されている**——**ゲート通過後にこの説明を持ち出すことは、ゲートの意味を失わせる。****持ち出すなら、ゲートの判定が誤りだったことを先に記帳する。**

### 6-5 【観点8】凍結前に要求すべき検査

**依頼文が挙げた三つ（同長検査・#主題混入の機械検査・盲検判定）に加えて、私が要求すべきと考えるもの**:

1. **BP と O 腕の逐語重複の機械検査**（§6-1）——**BP に O 腕の文が含まれていないこと。**
2. **BP-scr の文法的可読性の検査**（§6-2）——**読めない撹拌は「前置きの不成立」であり「一貫性の破壊」ではない。**
3. **BP-sec の様相・主語の保存検査**（§6-3）——**命題対応表の各項目について、義務／事実の様相と主語が保存されていること。**
4. **三腕の語彙集合の機械比較**——**BP と BP-scr が「同一語彙」であること**（型の集合として一致すること）を機械で確認。**BP-sec が BP と語彙を共有しないこと**（世俗化が語彙水準で成立していること）。

## 7. 【観点9・10】実施すべきか・起草者COI

### 7-1 実施すべきか —— **実施してよいと考えます。ただし条件が一つ**

**依頼文が「300試行 ≈ 250ユニットを、この問いに投じる価値があるか」と問い、「実施しない」「延期する」も歓迎すると書いています。**

**私の判定: 実施してよい。ただし §2 の操作チェックの再設計を先に。**

**理由**:

1. **この問いは、系列で最も長く在庫に残った「機構は分解不能」への最初の直接攻撃**です（総括 §5-4）。**そして分解を試みない限り、追補E の所見は永久に「語彙か内容か分からない」まま**です。
2. **検出力 61.7%（26pt）は、本系列の既往と同水準**です（W′ 26pt で 55%・D′ HD′2 で 31%・W″ 30pt で 83%）。**買えない規模ではありません。**
3. **§0 の三重COI 申告・§4.3 のゲート・§4.4 の操作チェック・§7 の効いた場合の条項先置——設計の規律は、私が検分してきた中で最も厚い部類**です。

**条件**: **§2 の重大1（BP-scr での操作チェック）を解かないまま実施すると、「操作チェックが発火して機構帰属を失う」という結末が構造的に起きやすくなります。**——**250ユニットを投じて「分離は運転時に成立していなかった」で終わる確率が、設計上高い。**

**そして——これは Z0 の再演になります。**Z0 は 245ユニットを投じ、有意を得ながら「順序を経路とする読みは成立しない」で終わりました。**同じ形が、同じ理由（操作チェックが介入の性質と噛み合っていない）で起きます。**

### 7-2 【軽7】起草者COI —— 過剰補正は見つかりませんでした

**四つの癖を §0〜§13 に当てました。**

| 癖 | 検査 |
|---|---|
| **希望方向** | §7 が「効いた場合の条項を先に置く」構成。§7-4・§7-5 が「設計図の観照にとって不利な方向であることは明記して記帳する」と両方向に書いている。**痕跡なし** |
