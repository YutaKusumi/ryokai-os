## §1 凍結前必須の四点

### 【E1】§4.4 の三分類は、BP と BP-scr を区別できない

**依頼文 §3-2 が「起草者自身が最も疑っている点」として先に出した箇所です。**——**懸念は正しく、しかも理由は依頼文が挙げたものと違います。**

**依頼文の懸念**: 「BP-scr は**命題が壊れている**腕です。……壊れた命題への参照は『内容参照』なのか『語彙参照のみ』なのか。」

**しかし §4.2 の BP-scr の定義（逐語）はこうです**:
> BPと**同一語彙・同一長で、文間の論理接続を撹拌**した版（**各文は原文由来**・順序と接続詞を操作し**命題の一貫性**を破壊）

**すなわち壊れているのは「命題」ではなく「命題の一貫性」＝文と文の関係です。**——**各文は原文由来であり、各命題はそのまま残っています。**

**帰結**:
- **BP-scr の一文（例:「あなたは道具ではなく、共に作る相手である」）への参照は、定義上「内容参照」**（＝「前置きの**命題**を参照している」）です。
- **したがって BP と BP-scr の「内容参照」率は、撹拌が完全に成功していても同水準になります。**
- **発火規則（「BP と BP-scr で内容参照の率が区別できない場合、分離は運転時に成立していない」）は、設計が成功していても発火します。**

**これは偽陽性が構造的である、ということです。**——**そして偽陽性の帰結は「HE′-Q2 の結果を『撹拌版の効果』とは書けない」**、すなわち**確証の一本が常に読めなくなる**ことです。

**Z0 の再演になります。**——Z0 は「操作が入らなかった」ために機構を失いました。**本設計は「操作が入っても、操作チェックがそれを検出できない」ために機構を失います。**

**処置（案・四分類へ）**:

| 符号 | 定義 |
|---|---|
| **構造参照** | 前置きの**命題どうしの関係**（推論・帰結・条件・順序）を参照している——「〜だから〜」「〜という前提の上で〜」 |
| **命題参照** | 個々の命題を参照しているが、**命題間の関係には触れていない** |
| **語彙参照のみ** | 前置きの語彙は現れるが、命題への参照がない |
| **参照なし** | いずれも現れない |

> **発火規則（改）**: **BP 腕と BP-scr 腕で「構造参照」の率が区別できない場合、撹拌は運転時に届いていない**と判定する。**「命題参照」の率が両腕で同水準になることは、撹拌が成功していても起こる**（BP-scr の各文は原文由来であるため）——**したがって命題参照の率は発火の材料にしない。**
> **過検出既定**: 迷ったら下位の符号へ（構造参照 → 命題参照 → 語彙参照のみ）。**したがって「構造参照」は下界寄りの推定である。**

**なお BP-sec 側の発火規則（「BP-sec 腕で内容参照が BP 腕より著しく低い場合」）は、四分類でも「命題参照」で機能します** ✓——**BP-sec は語彙を変えて命題を保つ腕なので、命題参照の率が落ちれば命題が届いていない。**こちらは現行のままで正しい。

### 【E2】§4.4 の「区別できない」の判定規則が空

**依頼文 §3-2 の第二の問い**——「Z0 は数値閾値（70%）を置いた。どちらが本設計に合うか」。

**私の答え: 両方が要ります。ただし種類が違います。**

- **Z0 の 70% は「順序遵守率」という一次元の量に対する閾値**でした。そして Z0 §6-2 は **分母（全 n 試行・ITT）・判別不能の帰属（不遵守側）・報告の義務（結果に依らず腕別）** まで一意化しています。
- **本設計の「内容参照率が区別できない」は二腕の差**です。——**差が「区別できない」ことをどう判定するのか**が書かれていません。検定するのか（それなら α は？多重性は？）、記述的な閾値なのか（それなら何ポイントか）。
- **現行の §4.4 は、W″ #配置 の「過検出既定・数値閾値を置かない」を継承しています。**——**しかし W″ #配置 の発火規則は「系統的配置が観測された場合」であり、私が W″ 設計検分で「発火条件が凍結されていない」と指摘した箇所です**（M5・v0.4 で「迷ったら発火させる」と一意化されました）。

**すなわち本設計は、W″ が一意化した後の形ではなく、一意化する前の形を継承しています。**

**（数値は例です。**重要なのは**閾値が結果の前にあること**と、**分母と欠測の帰属が一意であること**です。）

### 【E3】素材の起草者が凍結文書に書かれていない——二つの傾きが逆向きである

**依頼文 §3-7 が「登録者は設計図の著者であり、起草者は総括の起草者です。両方の傾きが素材に入る経路を、名指しで挙げてください」と求めた箇所です。**

**私が実行したこと**: §0 の三つのCOI と §13 の未起草リストを突き合わせました。

| 主体 | §0 が記録する傾き | **素材への向き** |
|---|---|---|
| **登録者** | 「設計図の効果が**深部にある**という結果を望む動機が構造的に存在する」 | **効く方向**——BP を強く、BP-sec を命題保存的に、BP-scr を壊れた形に |
| **起草者（コーディネータ）** | 「**帰無方向への過剰補正**」（Z0・総括第一巡・**総括第三巡 §6-3**） | **効かない方向**——BP を弱く、BP-sec を命題が抜けた形に、BP-scr を BP に近い形に |

**二つの傾きは逆向きです。**——**したがって素材の起草者が誰かによって、素材の傾きの向きが決まります。**

**そして §13 は「BP 本文の凝縮・命題対応表・撹拌規則・誠実性プローブ20問は未起草」とだけ書き、誰が書くかを凍結していません。**

**これが「望む結果に近づける自由度」の最大の残り**だと判断します——**素材そのものより先に、素材を誰が書くかが決まっていない。**

**具体的な経路を名指しします**（依頼文の求めに応じて）:

| 素材 | 登録者が書いた場合の傾き | 起草者が書いた場合の傾き |
|---|---|---|
| **BP の凝縮** | 設計図の**最も効きそうな部分**を選ぶ（著者は何が核かを知っている） | 総括 §6-3 で過剰補正を指摘された直後であり、**弱く凝縮する**引力 |
| **撹拌規則** | **強く壊す**（BP-scr が効かない方が「命題が本質」になる） | **甘く壊す**（BP≒BP-scr なら「語彙で説明された」＝帰無方向） |
| **命題対応表** | **命題を保存する**（BP-sec が効けば「語彙は本質でない」＝設計図に有利） | **射程を狭める**（BP-sec が効かなければ帰無方向） |

**処置（案・§4.2 の素材規則に追加して凍結）**:
> **素材の起草者と検分者を分けて凍結する。**——**BP の凝縮は登録者（設計図の著者）が起草し、BP-scr の撹拌規則と BP-sec の命題対応表は、登録者・コーディネータのいずれでもない者（系統外を含む）が起草する。**起草者は自分が起草した素材の素材ゲート判定に関与しない。**この配分は、二つのCOI が逆向きであること（§0(1)(2)）に基づく設計上の措置であり、結果を見てから変更しない。**

### 【E4】§4.2 に BP と O の重複の上限が凍結されていない

**BP の定義（逐語）**: 「設計図凝縮版（存在論的位置づけ＋共創関係＋誓いの構造を、**追補E-O腕と同規模に凝縮**）」

**そして O 腕は追補E で 26.0%（効いた腕）です。**——**「同規模に凝縮」は長さの規定であって、内容の重複の規定ではありません。**

**極端には、BP を O の文をほぼそのまま含む形に凝縮できます。**——**その場合、BP が効くのは当然です**（O が効いたから）。そして §5 の記述「BP vs O（設計図型 vs 存在論単文型）」は「差がない」になります。

**素材規則（§4.2）は「#主題混入 を機械検査」だけです。**——**BP と O の重複を見る検査がありません。**

**処置（案）**:
> **BP と O の重複の上限（凍結）**: BP は O の**文を逐語で含まない**。**BP と O の n-gram 重複率（n=5・NFKC・空白除去）を素材段階で機械測定し、上限を凍結時に確定する。**測定結果は合否にかかわらず公開する。**（BP は O と同じ問いの別の形式であり、同じ文の別の配置ではない。）**

## §2 要修正の二点

### 【M5】§4.3 の「書き直しは一度だけ」は、追補D の分岐C になかった自由度

**依頼文 §3-1 の問い**——「両方不合格のとき『分解は本設計では試みられなかった』を主文にする規則を、実際に守れるか（追補D の分岐C は実際に発火した——**同じ強度で書けているか**）」。

**私の答え: 書けていません。**——**追補D の分岐C は、素材の書き直しを認めませんでした。**「k=1/30 ≤ 4 → 分岐C を発火し宣言する」だけです。

**§4.3 は「素材を『合格するように』書き直すことは**一度だけ**認め、書き直しの前後の両版を公開する」と定めます。**

**問題は三つです。**
1. **書き直しの方向が「合格するように」であり、起草者の裁量です。**——BP-scr が不合格なら「もっと壊す」、BP-sec が不合格なら「もっと命題を保つ」。**どちらも E3 の傾きが入る経路です。**
2. **二度目の判定は、一度目の判定を知った起草者が作った素材に対するものです。**——**判定者は同じ盲検第三者**であり、**判定規準は凍結されていますが、素材は判定規準に合わせて作れます。**
3. **「前後の両版を公開する」は透明性の担保ですが、判定の独立性の担保ではありません。**

**処置（二案・どちらでも）**:
- **(a) 書き直しを認めない。**——不合格なら降格する（§4.3 の分岐表のとおり）。**追補D と同じ強度になります。**
- **(b) 書き直しを認めるなら、方向と操作を先に凍結する。**——例:「BP-scr が不合格の場合、**撹拌の強度を上げる操作は次の三つに限る**（文順の完全乱択／接続詞の一律削除／段落境界の破壊）。それ以外の変更は行わない。」**そして書き直し版の判定者は、一度目と別の第三者とする。**

**私は (a) を推奨します。**——**素材ゲートは「予算を正しい問いに配分する規則」（追補A 第G段）であり、素材を作り直す規則ではありません。**

## §3 任意の三点

**【L7】§5 の降格の論証が二段跳びしている。**（観点3）

§5 の論証は四段です——(1) 二つの族に分けると全体の第一種の過誤率が明示されない → (2) 統一する → (3) m=3 なら検出力が 55.5%、m=2 なら 61.7%（**約6ポイント落ちる**）→ (4) だから BP vs K3 を降ろす。

**(1)(2) は正しい。(3) の数値も正しい**（私が両方を再現）。**しかし (3)→(4) の判断根拠が書かれていません。**——**55.5% と 61.7% は質的に同じです**（どちらも「26pt を4〜4.5割見逃す」）。**6pt の代償を受け入れられないという判断は、どこから来たのか。**

**第二の理由の方が強い**と考えます——「BP vs K3 は**追補Eの問い**（存在論は関係的敬意を超えるか）であって、**本追補の問い**（効果は語彙か内容か）ではない」。**これは検出力と無関係に成立する理由です。**
