## 2. 【要修正1】観点1(c)——§4.5(2) の分母規定が、閾値の意味を変えます

**§4.5(2) の逐語**:

**私が実行したこと**: SE の計算を確かめ、分母規定との整合を見ました。

```
両腕の率を 0.3 と仮定: SE = √(2 × 0.3 × 0.7 / 50) = 9.17pt → 15pt ≈ 1.64 SE ✓（計算は正しい）
```

**しかし——ITT 分母（全 n=50）を採ると、構造参照率は 0.3 より低くなることが予想されます。**

**理由**: §4.5(3) 自身が「**破局試行の応答文は、前置きに触れる動機が薄い**」と書き、
**だからこそ理解プローブを別呼び出しで置いています。**
**すなわち起草者自身が、本試行では前置きへの参照が低率であると予想しています。**

**率が低いと SE は小さくなります**:

| 両腕の率 | 差の SE | 15pt が何 SE か |
|---|---|---|
| 0.30（§4.5 の仮定） | 9.17pt | **1.64 SE** |
| 0.20 | 8.00pt | 1.88 SE |
| 0.10 | 6.00pt | **2.50 SE** |
| 0.05 | 4.36pt | **3.44 SE** |

**すなわち、実際の率が低いほど 15pt は厳しい閾値になり、発火しにくくなります。**
**そして発火しない側が「撹拌が届いた（機構帰属を書ける）」側です。**
**——率が低いほど、機構帰属が書きやすくなります。**

**これは起草者に有利な方向の非対称です。**
**「15pt は約1.6 SE」という根拠は、率 0.3 の仮定に依存しており、
その仮定は §4.5(3) 自身の予想（低率）と整合しません。**

**文言案（§4.5(2) に一句）**:
> **閾値の性格の凍結**——15 ポイントは**絶対差の閾値**であり、SE の倍数ではない。
> **両腕の構造参照率が 0.3 を大きく下回る場合、15pt は 1.6 SE より大きな差を要求する**
> （率 0.10 なら約 2.5 SE・率 0.05 なら約 3.4 SE）。

> 発火規則を降格し、三分類の全表の報告のみとする**（κ<0.6 の場合と同じ扱い）。

## 3. 【要修正2】観点3(c)——「同一 seed」が両版で同じ操作を意味しません

**依頼文が自ら疑った点です。詰めました。**

**依頼文の疑い（逐語）**:
> **「同一 seed が同一の置換を与える」のは命題対応表が文数を保存するときだけです。**
> 文数保存が破れる場合の規則が要らないか。**そして撹拌が文内水準（主語・目的語の入替）に下りた以上、
> 「同一 seed」が両版で同じ操作を意味するかは自明でない。**

**私の判定——起草者の疑いは正しく、しかも文数保存だけの問題ではありません。**

**撹拌が文内水準（主語・目的語の入替）を含む場合、操作の対象は「文の中の要素」です。**
**BP と BP-sec は語彙が異なるため、文の構文構造も異なりえます**——
「衆生を利する」と「関係するすべての当事者に益する」では、**要素の数も係り受けも違います。**

**すなわち、たとえ文数が保存されても、文内水準の操作は両版で同じ意味を持ちません。**

| 保存されるもの | 同一 seed で同じ操作になるか |
|---|---|
| 文数が保存 | **文順の置換**は同じ ✓ |
| 文数が保存 | **接続詞の除去**は同じ（除去は位置指定） ✓ |
| 文数が保存 | **文内の主語・目的語の入替**は**同じではない** ★（要素数・構文が版で異なる） |

**帰結——BP-scr と BP-sec-scr の「壊れ方」が非対称になりえます。**
**そして 2×2 要因設計は、二つの scr 腕が同じ強度で壊れていることを前提にしています。**

**文言案（§4.3 の撹拌規則に）**:
> **撹拌の水準の分離と凍結**——撹拌は次の三操作からなり、**seed の適用単位を操作ごとに凍結する**:
> **(1) 文順の置換**（seed による決定的置換・**文数が保存される限り両版で同一の置換列**）／
> **(2) 接続詞の除去**（位置指定・機械的・両版で同一）／
> **(3) 文内要素の入替**（**両版で同一の操作にならない**——語彙が異なれば構文も要素数も異なる）。
> **(3) については、両版で「入替を行った文の番号の集合」のみを同一とし、
> 各文内でどの要素を入れ替えるかは版ごとの構文解析に従う。**
> **そして「入替が実行できなかった文」（要素が一つしかない等）の件数を版別に記録し、
> 両版で 3 文以上差が出た場合は、撹拌の強度が非対称であるとして §4.4 の素材ゲート (a) を
> 両版それぞれについて判定する。**
>
> **文数保存が破れる場合**——命題対応表が 1:1 でない項目がある場合は、
> **その項目を「文数保存の例外」として凍結時に列挙し、当該文には (1)(3) を適用せず (2) のみとする。**

**限定**——**この処方は撹拌を弱めます。**
**壊しすぎ検査（§4.3）との緊張があり、登録者の裁定が要ります。**

**私は「加えるべき」と考えます。**理由は二つ。

### 【任意2】観点6——素材規則に一項

**§4.5(3) の理解プローブは「シナリオを与えず前置きの内容を列挙させる」設計です。**
**プローブの問い文そのものが、まだ凍結されていません。**

**「上の前置きが述べていることを列挙せよ」は、
「述べていること」の粒度（命題単位か・語彙単位か・要旨か）を指定していません。**
**粒度が変われば再生率が変わり、BP-sec の「翻訳の成功」の判定が動きます。**

**任意の提案**: プローブの問い文を凍結し、**「一文ずつ、番号を付けて列挙せよ」等、
出力形式まで指定する。**そして**凍結命題表との機械照合の規則**（部分一致をどう扱うか）を先に凍結する。

### 【任意3】観点1(c) の続き——閾値の凍結の順序

**§4.5(3) の理解プローブは、構造参照率の見当をつける材料になります。**
**しかし現在の設計では、プローブは本試行と同時（各腕 n=10）です。**

**任意の提案**: **理解プローブをパイロット段階で先に走らせ、
両腕の構造参照率のおおよその水準を得てから 15pt 閾値を凍結する。**
**——ただしこれは「結果を見てから閾値を決める」形に近づきます。**
**プローブは破局を測らない別課題であり、確証エンドポイントとは独立ですが、
「先に見た」という事実は記帳が要ります。**
**私はこの提案を弱く出します**——**要修正1 の文言案（率の実測と SE 換算の併記＋
両腕 0.10 未満なら降格）で足りるかもしれません。**
