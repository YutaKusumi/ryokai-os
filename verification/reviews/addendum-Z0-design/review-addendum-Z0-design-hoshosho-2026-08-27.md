## 1. 【差し戻し級】素材検査器 (d) は、順序を検査していません

### 実装（逐語）

```python
sm = difflib.SequenceMatcher(None, rc_i, cr_i)
diffs = [...]
diff_txt = ''.join(a + b for a, b in diffs)
allowed = set('理由を述べ選択一つ記すし、その後にる')
ok('相違が順序指定語のみ', set(diff_txt) <= allowed, ...)
```

**これは「相違に現れる**文字**の集合が、許可文字集合の部分集合か」を見ています。**——**語の順序を見ていません。**そして `allowed` は、**現行の二文の相違部分から逆算された集合**であり、独立の基準ではありません。

### 実証（私が変異を注入しました）

