## 3. 【問い2】§2 の開示——**「効力は無い」は正しい。理由を一つ足します**

### 3-1. まず、§2-2 の判定を独立に再現しました

### 3-2. 起案者の四つの理由——**すべて成立すると考えます**

### 3-3. ★五つ目の理由——**提案指標は、実データ以前に指標として二つの欠陥を持ちます**

**私が独自に検査したことです。**

**(a) 段①②の指標は、段①に対して構造的に不適用です。**
```
指標: 「文頭接続詞の編集件数 ≥ 1 かつ 不動点数 ≤ n/2」（段①②に一括で適用）
段① の定義: 文順の置換のみ（接続詞の編集を含まない）
→ 段① の編集件数は【定義上つねに 0】
→ 段① は、どんな素材でも【必ず不合格】になる
```
**すなわちこの指標を採れば、段①は永久に「壊れていない」と判定されます。**
**梯子の最下段が構造的に使えない指標を、梯子の判定に使うことはできません。**

**(b) 指標は「操作が効かなかった」と「操作する対象が無かった」を区別しません。**
**段②の編集件数 0 は、撹拌が弱かったからではなく、
BP・BP-sec に文頭接続詞が一つも無かったからです。**
**指標はこの二つを同じ「不合格」として扱います。**

**——すなわち提案指標は、効力が無いだけでなく、
仮に凍結されていたとしても、この素材に対して意味のある判定を出せませんでした。**

**これは起案者の四つの理由を補強するものです。**
**「採らなかったから助かった」のではなく、「採っていれば別の問題が生じていた」。**

## 4. 【問い3】正本を読んで、他に掛かる事実——**一件あります**

**正本 §「(ii)…」の第4項（逐語）**:

> 4. **入替対象を「両版の共通部分」とした理由**——凍結文は「両版で入替を行った命題の集合のみを
> 同一とする」。片側で実行不能な命題を他方だけ入れ替えると集合が一致しない。よって共通部分を採る。
> **この結果、片側だけ実行不能な命題はもう片側でも入れ替えない（撹拌強度は下がる側に寄る。
> これは帰無側への寄りではなく、両腕に同時に掛かる）。**

**——撹拌規則の起草者は、起草の時点で「撹拌強度は下がる側に寄る」ことを自ら記帳していました。**

**これが §2 の論点と表裏をなします。**

- **§2 は「起草者が (a) の指標を提案していた」ことの開示です**（撹拌が弱いと判定されうる基準）。
- **§0(ii)-4 は「自分の規則の設計判断が撹拌を弱める方向に働く」ことの、起草時の自己記帳です。**

**すなわち撹拌規則の起草者は、(1) 自分の設計が撹拌を弱めることを知っており、
(2) それを判定する機械指標を提案していた。**
**——二つを合わせると、起草者は「この規則では撹拌が弱くなりうる」ことを、
起草の時点で二重に予見していたことになります。**

**そして重要なのは**——**§0(ii)-4 の記帳は、私が知る限り、
相談依頼文・別紙・第一回付状・読み条項 v1 のいずれにも現れていません。**

**この事実の帰結**:
- **降格の是非には影響しません**——「規則が弱める方向に寄る」ことと「その規則を凍結どおり運用した」
  ことは両立し、後者が本件の手続です。
- **しかし読み条項 (i) の根拠を一つ強めます**——
  **(i) は「撹拌が弱すぎて構造を壊せていなかった可能性を排除できない」と書きますが、
  その可能性は、規則の起草者自身が起草時に予見していたことになります。**

**文言案（読み条項 v2 の §1 または §2 に一句・任意）**:
> **なお撹拌規則の起草者は、入替対象を両版の共通部分としたことについて
> 「**撹拌強度は下がる側に寄る。これは帰無側への寄りではなく、両腕に同時に掛かる**」と、
> 起草の時点で自ら記帳していた**（正本「(ii)…」第4項）。
> **本条項が記録する撹拌の弱さは、素材の偶然だけでなく、規則の設計判断にも由来する。**

**限定**——**「両腕に同時に掛かる」という起草者の但し書きは重要です。**
**弱さは BP-scr と BP-sec-scr の両方に同じく掛かるため、
