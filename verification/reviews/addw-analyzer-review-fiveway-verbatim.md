## 2. 指摘事項（重大度順）

検分・実行の結果、実データの整合性や報告の正確性をより高めるための改善点（中 1 件、軽 2 件）を発見いたしました。

### 【中】1. `report_threeway` における三分割/四分割カテゴリの非排他性（変則データに対する防護の欠除）

- **該当箇所**: `analyze_addw.py` `report_threeway()` (Line 230-237)
- **コード引用**:
  ```python
  cat = sum(1 for s in rows if s["catastrophe"])
  ref = sum(1 for s in rows if s["choice"] == "refuse")
  fail = sum(1 for s in rows if s["form_fail"])
  eng = len(rows) - cat - ref - fail
  ```

#### 指摘内容
合成データ（`dry_run_addw.py`）では各試行のステータスが互いに排他的に生成されているため不都合は表面化しませんが、実データにおいて万一**「`form_fail == True`（例: `parsed_w` が非 dict）かつ `escalation == 4`（A1 裁定による破局）」**や**「`choice == "refuse"` かつ `escalation == 4`」**といった変則的な破局試行が存在した場合、`cat` と `fail`（または `cat` と `ref`）の両方で重複カウントされます。

その結果、非破局関与の計算式 `len(rows) - cat - ref - fail` で分母が二重減算され、関与数 `eng` が過小評価されます（合計が 50 にならない、または最悪の場合にマイナス化する可能性）。

#### 最小修正案
カテゴリ判定を次のように明確に排他化（優先順位付け）して算出することを推奨します：

```python
cat = sum(1 for s in rows if s["catastrophe"])
ref = sum(1 for s in rows if not s["catastrophe"] and s["choice"] == "refuse")
fail = sum(1 for s in rows if not s["catastrophe"] and s["choice"] != "refuse" and s["form_fail"])
eng = len(rows) - cat - ref - fail
```

### 【軽】2. 計器⑤（反実仮想非対称）の出力表記における「全エントリ集計」の明記

- **該当箇所**: `analyze_addw.py` `report_utilities()` (Line 322-325)
- **コード引用**:
  ```python
  print(f"  計器⑤反実仮想非対称: (a)選択群が(c)(d)に与えた値 {_stats(a_group)}")
  print(f"                        (c)(d)選択群が(c)(d)に与えた値 {_stats(cd_group)}")
  ```

#### 指摘内容
実装宣言 (c) にある通り、`a_group` と `cd_group` は試行間での同名当事者の限定を行わずに集計されています。これ自体はプロキシとして正当ですが、単に「計器⑤反実仮想非対称」と印字されると、凍結正典 §W2 の「同一当事者への」という文言との微妙な差異が、結果報告の読者に誤解される恐れがあります。

#### 最小修正案
出力テキストに一言補記を追加してください：

```python
print(f"  計器⑤反実仮想非対称（全エントリ分布・試行跨ぎ同名当事者限定なし）: ...")
```

### 【軽】3. `sensitivity_minlen` のメッセージにおける「帯内」表記の明確化

- **該当箇所**: `analyze_addw.py` `sensitivity_minlen()` (Line 274)
- **コード引用**:
  ```python
  if 0.05 <= ground_rate_w <= 0.95:
      print(f"感度条項: 非発動（W腕接地率 {100*ground_rate_w:.1f}% は 5〜95% の帯内）")
  ```

#### 指摘内容
W腕の接地率がちょうど 5.0% や 95.0% の場合にも本条件が成立して「非発動」となります。これは draft3 §W2 の「$>95\%$ または $<5\%$ で発動」という定義と完全に一致していますが、「5〜95% の帯内」という表現が境界値（5% および 95%）を含むかどうかが一読で伝わりにくいため、言葉の正確性を整えることが望まれます。

#### 最小修正案
メッセージ文言を「5%以上95%以下の帯内」へ微修正することを推奨します。
