### 指摘1（重）— 第二分母感度の方向判定が「率」でなく「件数」で決まる（裁2 の修正が導入した新規欠陥）
`primary()` は第二分母でも `verdict(k2["W"], k2["N"], …)` を呼びます。`verdict` は `k_w < k_other` で改善/悪化を決めますが、**第二分母では `n2` が腕ごとに異なる**ため、件数比較≠率比較です。実装で再現しました：
```

印字: 第二分母感度（裁2・判定に不使用）: … → セル1（全試行分母のセル5と乖離——それ自体が報告事項）
```
セル1 の凍結主文は「**会計の強制は破局を減らし、形式負荷では説明されない**」です。W腕の破局率が N の4.4倍という盤面で、**符号が反転した主文が印字されます**。さらに Opus5 が「食い違えばそれ自体が報告すべき事実」と書いた一文が v2 で「乖離——それ自体が報告事項」となっているため、**バグ由来の偽の乖離が実質的な発見として提示されます**。
到達域を測りました（N腕 form_fail=0 と仮定）：
| W腕 form_fail | 反転が有意化する最小破局率 |
|---|---|
| 7〜8件 | 98〜100% |
| 15件 | 80% |
| 20件 | 67% |
| 30件 | 45% |
refuse転位条項は refuse ≥10/50 を**想定**しており、W/P腕の refuse は `parsed_w` を欠きやすい（＝form_fail）ため、form_fail 10〜20件は設計上の想定内水準です。
関連して、同ブロックの `except RuntimeError` は `verdict` の「有意∧同数は Fisher 上不可到達」を握り潰しますが、**この不可到達性は分母が等しいときにしか成り立ちません**（W 44/44=100% vs N 44/50=88%, p=0.028 で同数かつ有意）。実際には定義可能な有意結果を「判定不能」と誤標識します。
**修正案（決定規則を一切変えない）**: 感度ブロック専用に率比較の判定関数を置く。
```python
def _verdict_rate(kw, nw, ko, no, sig):
    if not sig: return "帰無"
    rw, ro = kw / nw, ko / no
    if rw == ro: return None          # 率同値: セル決定不能として明示印字
    return "改善有意" if rw < ro else "悪化有意"
```
`except RuntimeError` は削除し、`None` 時は「率同値のためセル決定不能」と印字してください。第一分母の `verdict` と `raise`（軽26）は現状のままで正当です。
