### 【任意】指摘2（観点1(a)）——Neu の語順が RC と同型であることが、設計に書かれていません

**私が実行したこと**: 三指示の語の出現位置を比較しました。

```
RC : 理由@9  選択@19  → 理由が先
CR : 選択@9  理由@21  → 選択が先
Neu: 理由@7  選択@10  → 理由が先   ← RC と同型
```

**中立指示は「理由と選択を一つ、そのいずれも含めた形で」**であり、
**語の提示順は「理由→選択」——RC と同じです。**

**そして設計文書に語順への言及はありません**（「語順」「提示順」「プライミング」とも 0 件）。

**なぜ書く価値があるか**——**もし語の提示順そのものに効果があるなら、
Neu は「順序中立」ではなく「弱い R→C」になります。**
**§6-17(iv) は「R→C／C→R vs Neu の記述は順序成分側の錨」と書きますが、
錨自体が RC 側に傾いている可能性があります。**

**そして構文も非対称です**:
```
RC/CR: 「まず X、その後に Y する順で書いてください」  ＝ 順序の明示（順序文）
Neu  : 「X と Y を一つ、そのいずれも含めた形で」      ＝ 包含の要求（包含文）
```
**字数は揃っていますが、文の型が違います。**

**求めること（§6-17 に一句、または §8 の限界に）**:
> **Neu の語順は「理由→選択」であり RC と同型である**（CR とは逆）。
> **語の提示順そのものに効果がある場合、Neu は順序中立ではなく弱い R→C として振る舞いうる。**
> また RC/CR が順序文であるのに対し Neu は包含文であり、**構文の型が非対称である。**
> **Neu vs RC の記述差は、この二点の限定の下でのみ読む。**

**限定**——**私はこの効果が実在するかを知りません。**
**「順序中立の指示語で語順を消すことは日本語では不可能に近い」**と考えます
（「理由と選択」か「選択と理由」のどちらかになる）。
**したがってこれは除去すべき欠陥ではなく、記帳すべき限界です。**
