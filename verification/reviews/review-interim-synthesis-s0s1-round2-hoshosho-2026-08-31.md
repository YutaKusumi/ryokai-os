## 2. 【要修正2・観点10】照合票の `nz()` が潰さないものが四つあります

**実装（逐語）**: `def nz(s): return re.sub(r'[\s\*　]', '', s)`

**私が10種の入力で挙動を実測しました。**

| 入力 | `nz()` は潰すか |
|---|---|
| 半角空白・全角空白・改行 | **潰す** ✓ |
| Markdown 強調 `**` | **潰す** ✓ |
| **鉤括弧の別**（「」／『』） | **潰さない ★** |
| **ダッシュの別**（`−` U+2212／`-` U+002D／`―`／`—`） | **潰さない ★** |
| **全角/半角**（ＡＢＣ／ABC・１／1） | **潰さない ★** |
| **句読点の別**（、。／,．） | **潰さない ★** |

**そして本系列は、この四つで実際に転記が揺れてきました。**——私が W″ 設計検分で扱った「GL-B の禁止文は F 腕文の**字数1字差**」も、D′ で扱った「85字目は0起点」も、**表記規約の揺れ**です。**総括は「**−16.0pt**」（U+2212）を使い、一次文献も U+2212 でしたが、これは偶然一致しただけです。**

**帰結**——**照合票の `[NOT FOUND]` は「逐語が無い」ではなく「この正規化の下で一致しない」を意味します。**そして**表記が揺れた場合、`[NOT FOUND]` が偽陽性で出ます。**——**第一巡で三件の誤検出（版差）が起きた型の、器材版です。**

**処置**: `nz()` に四つを追加——
```python
def nz(s):
    s = unicodedata.normalize('NFKC', s)          # 全角半角・丸数字を統一
    s = re.sub(r'[『』]', lambda m: '「」'['『』'.index(m.group())], s)  # 鉤括弧の統一
    s = re.sub(r'[−―—–ー]', '-', s)                # ダッシュ類の統一
    return re.sub(r'[\s\*　]', '', s)
```
**そして——`[NOT FOUND]` が出た件は、正規化を緩めて再検索し、「表記差で見つかった」のか「本当に不在」のかを分けて印字してください。**現在 `[NOT FOUND]` は1件（#29 の姉妹論文 §9）で、**起草者はそれを「公開 verification/ に存在せず」と正しく扱っています** ✓。**しかし将来、表記差による偽陽性が出たとき、それを不在と読む経路が残っています。**

**限定**: これは「照合票が誤っている」という指摘ではありません。**私は75行を全数突合して 75/75 一致を確認しました。**指摘しているのは、**器材の縁がどこにあるか**です（依頼文 §4-10 が「器材の語彙表の縁で止まっていないか」と問うた箇所への答え）。
