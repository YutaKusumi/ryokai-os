## 1. これは何か、そして今なぜ §0・§1 だけを回すのか

**中間総括**（第一波〜追補Z段0）の最初の二節である。文書全体の構成は登録者裁定により
§0 何が確証され何がされていないか → §1 柵の合成表 → §2 旅程 → §3 器材と規律の系譜 →
§4 較正の通史 → §5 測れなかったものの目録 → §6 仮説の絵（非主張） → §7 在庫の採否裁定 →
§8 次の登録の候補設計、と定めた。

**§0 と §1 を先頭に置き、かつ先に検分に回すのは意図的である。**——総括は「並べたものが収束する
証拠に見える」誤りが最も起きやすい場所であり、**絵（§6）を描く前に、絵を禁じる表を先に立てて
検分に晒す**という順序そのものが本文書の設計判断である。§2 以降は本検分の後に起草する。

**位置づけ**: **登録外・二次文献**（current-position 系列と同じ棚）。ただし参照規律を一段厳しくし、
数値は一次文献から引用して総括の場で再計算する・current-position 系列からは経緯と工程の事実のみを
採る、と定めた（§冒頭）。

## 3. 検分の観点（8項目）

1. **§0 の六型分類は凍結の逐語に忠実か。**——とくに「**有意だが、凍結条項が機構への帰属を禁じた**」
   （W″ の K・Z0 の HZ0）という型の新設が妥当か。誤分類・型の取りこぼし・型どうしの境界の曖昧さ。
2. **§0 の数値の独立再計算。**p 値・件数・率・n を一次文献から確認されたい（本文書は各行に URL を
   附記している）。**転記の誤り**は本系列が繰り返し数えてきた型である。
3. **§1-0「柵の系譜」の事実確認。**——「初期の追補には独立した柵の節がなく、W′ §7 十三条が最初」と
   書いた。**これは事実か。**（起草者はエージェント抽出＋自身の確認で判断したが、原典を最もよく知る
   のは各追補を検分された方々である。）
4. **§1-1 の掘り出しの網羅性——本巡で最も重要な観点。**
   **あなたが検分した追補の読み条項のうち、追補をまたぐ読みを禁じているのに §1 に載っていないものは
   ないか。**§1 は「散在している制限を掘り出して同じ台帳に載せる」作業であり、**取りこぼしは
   検分でしか見つからない**。
5. **敵対的検分（明示的にお願いする）。**——**§0 と §1 だけを手に持って、禁じられている横断読みを
   書けてしまうか。**たとえば「規則は計算より強い」「敬意は効くが履歴は残らない」「介入は効くが
   モデルは指示に従わない」といった総括を、この二節の記述から組み立てられるなら、**柵に穴がある**。
   自前で穴を作って報告されたい（追補Z0 設計検分で三名が (d2) を実際に破った様式の継承）。
6. **§1-3（総括に固有の四条）は十分か・過剰か。**とくに条27（**較正の通史を判断の重みづけに用いない**・
   W″ §10-16 の適用）は、§4 を書く前に置く柵として機能するか。
7. **参照URLの正確さ**——リンク先が、本文書が引いている主張・数値を実際に支えているか（抽出は
   エージェント経由であり、**起草者は全26件の解決は検査したが、全リンク先の内容と本文の対応は
   人手で全数照合していない**——申告）。
8. **起草者のCOI が §0・§1 に現れていないか。**起草者は COI 台帳に「希望方向へ読んだ」（#49・#52）・
   「面白い方向へ強く書く癖」（temp0・五件目）・「悲観方向への予想外れ」（W″ K側・D′）・
   「帰無方向への過剰補正」（Z0）と記録がある。**総括は「系列が一貫している」と読みたい引力が
   最も強い場所**である——その引力が、型の切り方・柵の選び方・強調の置き方に出ていないか。

## 4. 申告のお願い（登録者指示・本巡から様式化）

**登録者の指示により、本巡から以下の申告を検分報告の必須項目とする**——
「**検分者が何を見て（見ず）検分を行った（行わなかった）かがわかることで、検分の質が向上する**」。

各報告に、次の四点を明記されたい:

1. **開いたもの**——本文書のほか、**どの一次文献（URL）を実際に開いたか**。「開いていない」も
   同じ重さで書く（本系列は「読了申告 ≠ 検査」を過去に実証している）。
2. **自前で計算・照合したもの**——再計算した数値・突合した逐語・走らせた器材があれば具体に。
   なければ「行っていない」と明記。
3. **行わなかった検査**——観点1〜8 のうち実施しなかったもの。**被覆の穴の申告**は本系列の様式であり、
   不履行の申告は減点ではない（申告しないことが問題である）。
4. **COI**——所属系列・当該追補への関与（設計検分・条項の提案・起草）。
   **とくに §1 に載っている柵のうち、あなた自身の指摘に由来するものがある場合は明示**されたい
   （例: Z0 §6-2 の分母規約・Z0 (d2) のホワイトリストと §11b・Z0 §6-17(v) の言及順・追補Z の原案）。
   **自分が置いた柵が正しく転記されているかを確かめる作業には、「正しく載っている」と書きたい
   引力が働く。**
