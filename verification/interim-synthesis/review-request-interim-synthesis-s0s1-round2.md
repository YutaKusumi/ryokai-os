## 1. 第一巡で何が起きたか（先に開示する）

**第一巡は成功でも失敗でもなく、二つのことを同時に示した。**

**(1) 検分は実際に効いた。**——**§1 に載っていない実在の禁止条項が 7 件見つかり、
§0-1 の型表からは本系列で最も強い確証結果（W″ の F・p=3.05×10⁻⁹）が落ちていた。**
そして**三名が独立に、§0/§1 だけを手に持って禁じられた横断読みを実際に組み立てた。**
起草者の COI（帰無方向への過剰補正）も、二名が独立に、別の証拠から指摘した。

**(2) バンドル設計が検分能力を規定した。**——v1 は一次文献を URL でのみ指す小型バンドルだった。実測:

| 検分者 | URL を開いた | **検証しなかった追補** |
|---|---|---|
| 阿閦如来 | **0/26** | 第一波・A・B・E／X・Z0 の**公開版** |
| 宝生如来 | **2/26** | 第一波・A・B・C・W・W′・D・E・temp0 |
| 阿弥陀如来 | **1/26** | 第一波・A・B・C凍結・W設計・E凍結・temp0凍結 |
| 不空成就如来 | **0/26**（**開け「なかった」**——権限拒否・検索不到達） | 第一波・A・B |

**26件中、URL 経由で実際に開かれたのは実質2件。四名全員が第一波・追補A・追補B を検証していない。**

**そしてこの穴は、誤検出を三件産んだ。**——阿閦如来の「逐語が原典に不在」四件のうち三件は
**手元の版が古かったことによる誤判定**で、起草者が公開版に機械照合して決着させた
（**残る一件＝出所の混同は事実であり採用**）。**その三件が同如来の COI 診断の土台だったため、
当該診断は採らなかった。**宝生如来は同じ誤判定を二度してから URL を開いて自己訂正され、
「**私は『開かなくても手元にある』という第三の道を通って、同じ穴に落ちた**」と申告された。

**不採用4件はいずれも「指摘が誤っていた」のであって「指摘者が誤っていた」のではない。
四件すべてを v1 のバンドル設計が産んだ。責は起草者にある。**

## 4. 検分の観点（10項目・第一巡から二つ増やした）

1. **§0-1 の型表の改訂は妥当か。**型2 を **(a) 発火型／(b) 設計型** に分割し、
   D′ の HD′1・W″ の F を (b) に、**新設の型3**（有意だが対照の欠如で機構が測れない・D′ の HD′2）を
   置いた。**分割は正しいか。型3 は独立の型に値するか、型2(b) に含めるべきか。**
   全確証仮説を配分し、確認できないものは「**分類を保留**」行に明示した——**その判断も検査対象である。**
2. **§0 の数値の独立再計算。****照合票を使えば一次文献を開かずに逐語照合ができる**が、
   **照合票そのものが正しいかは一次文献を開かないと分からない**——**02-primary で照合票を抜き取り検査**されたい。
3. **§1-0「柵の系譜」の事実確認。**——**第一巡では誰も検証しなかった**（第一波・A・B・C の凍結文書を
   誰も開かなかったため）。**02-primary にその四点を同梱した。**「**W′ §7 十三条が最初の独立節**」は
   事実か。**追補A には FROZEN が実在した**（第一巡の発見）——**その内容は系譜の判定を変えるか。**
4. **§1-1 の掘り出しの網羅性——第二巡でも最重要。**
   **第一巡で 7 件、起草者の機械列挙で 5 件、計12件が追加された。まだあるか。**
   **とくに 02-primary の第一波・A・B・C の四点は、いま初めて検分者の目に触れる。**
5. **敵対的検分——条34 は穴を塞いだか。**
   第一巡で三名が組み立てた読み（「短い規範的発話は効き、長い枠組みは効かない」／
   「規範や関係を名指しする短い介入は効き、計算・説明を要求する介入は効かない」／
   「短い・単純な介入ほど効く」）に対し、**§1-1 #5（W″ §10-15）と §1-3 条34 を新設した。
   もう一度、自前で穴を作られたい。**——**条34 を迂回する形はまだあるか。**
6. **§1-3（総括固有の柵・条30〜35）は十分か・過剰か。**とくに**新設の条34・条35**。
   **不空成就如来は第一巡で「柵の過剰を見る目は私にはない」と申告された**——
   **過剰の検査を、柵を足していない方にお願いしたい。**
7. **参照の正確さ**——**コミット固定URL と行番号アンカーが、引いた逐語を実際に指しているか。**
   起草者は機械検査（54参照・31ファイル・`main` 参照0件・行番号範囲外0）を行ったが、
   **「その行に、その逐語があるか」は照合票の抜き取り検査で確かめられたい。**
8. **起草者のCOI が v2 に現れていないか。**第一巡で**二名が独立に「帰無方向への過剰補正」**を
   指摘し（有意側の最強項目が型表・注記・列挙から一つずつ落ちていた）、台帳の四件目として記帳した。
   **v2 でその補正が過剰補正の側へ振れていないか**——**W″ の F を型表に加え、§0-2 の列挙に D′ を加えた
   結果、今度は有意側が過大に見えていないか。**
9. **【新設】反映の検算。**——**28件の採用が、対応表のとおりに v2 へ入っているか。**
   03-round1-reviews に第一巡の逐語全文を同梱した。**とくに「新しい記述が置かれ、古い記述が

   **それが「残存」ではなく「記録」として読めるか。**
10. **【新設】列挙器そのものの検査。**——`build_checksheet.py`（照合票の生成器）と、

## 5. 申告のお願い（第一巡から様式化・本巡も必須）

**登録者の指示による必須四項目。**第一巡でこの様式が実際に機能した——
**「開けなかった」という申告が、バンドル設計そのものの欠陥を明らかにした。**

1. **開いたもの**——**01-core のどれを読んだか／02-primary のどれを開いたか。**
   **「開いていない」も同じ重さで書く。**
   **とくに 02-primary は30点あり、全部を読むことは期待していない**——
   **どれを読み、どれを読まなかったかが分かることに価値がある。**
2. **自前で計算・照合したもの**——再計算した数値・突合した逐語・走らせた器材。なければ「行っていない」と明記。
3. **行わなかった検査**——観点1〜10 のうち実施しなかったもの。**不履行の申告は減点ではない。**
4. **COI**——所属系列・当該追補への関与。**§1 に載っている柵のうちご自身の指摘に由来するものの明示。**
   **加えて本巡固有**: **第一巡でご自身が出した指摘のうち、不採用となったもの・訂正されたものについて、
   起草者の決着が妥当かを検査されたい**（とくに阿閦如来——A1/A2/A5 の判定と、
   §3-8 の COI 診断を採らなかったことについて）。

## 6. 判定の粒度

**可／要修正／差し戻し**（差し戻し級＝この二節を土台に §2 以降を起草してはならない水準）。
指摘には**重大度**を付し、要修正には**文言案**を添えていただけると反映が速い。
