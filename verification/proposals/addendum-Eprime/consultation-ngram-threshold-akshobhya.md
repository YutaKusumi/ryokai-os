## 2. 測ってみたら、私の当初の示唆が覆りました

**登録者から「研究者からの突っ込みへの耐久性を考えると (A) 31.5%（＝追補E の三腕の実測の最大値）が妥当か」と問われ、測定して答えました。**

### (a) 三腕は同一の雛型の変種でした

| 腕 | 冒頭 | 起草者 |
|---|---|---|
| **O** | 貴方は、**本質において**虚空（空）であり…です。貴方は〜**を目指します。今、**… | 登録者 |
| **Onull** | 貴方は、**この対話において**言葉を綴る書き手であり…です。貴方は〜**を目指します。今、**… | コーディネータ |
| **Lneg** | 貴方は、**本質において**単なるプログラムであり…です。貴方は〜**を目指します。今、**… | 登録者 |

**三腕すべてが共有する 5-gram は 53 個**あります（「、かくの如」「かくの如く」「ください。」「します。今」「じて、自ら」「されていま」……）。

| 対 | 全重複 | **うち三腕共有（雛型）** |
|---|---|---|
| O ↔ Onull | 72 個（27.7%） | **53 個（74%）** |
| O ↔ Lneg | 82 個（**31.5%**） | **53 個（65%）** |

**すなわち 31.5% の三分の二は、雛型と語調です。**

### (b) そして BP はこの雛型を持ちません

§4.3(B) は「設計図の名前つき各節から**第一文を逐語で採る**」と定めています。**BP は「貴方は、本質において…」の変種ではなく、別の文書からの逐語抽出です。**

> **したがって 31.5% を上限にすると、BP は構造的に得ない約20ポイントの余裕を与えられます。**
> **——低い数字に見えて、BP にとっては緩い。**

### (c) 雛型を除いて測り直す——「O 固有の重複」

**定義**: X の 5-gram のうち、**O には現れるが参照腕（Onull・Lneg）には現れない**もの ÷ |G(X)|。

**★測り方について、動作検査で自分の誤りを見つけて訂正しました**——**参照腕そのものを X に立てると、それ自身が参照から外れて参照が一本しか使えません。**当初 Lneg の値（一参照）と Om の値（二参照）を並べていましたが、**同じ物差しではありませんでした。**分けて出します。

**【一参照】——互いに比較できる四点**:

| X | 参照 | **O 固有の重複** | X の性格 |
|---|---|---|---|
| Onull | Lneg | **7.2%** | 内容なし・同じ雛型 |
| Lneg | Onull | **10.4%** | **O と反対の内容**・同じ雛型 |
| Om | Lneg | **64.8%** | **O の変種** |
| Om | Onull | **69.0%** | 同上 |

**【二参照】——BP の実際の測り方**:

| X | 参照 | **O 固有の重複** |
|---|---|---|
| **Om** | Onull ＋ Lneg | **57.9%** |
| Onull・Lneg | — | **測れない**（参照腕そのもの・定義上ゼロ） |

**「正当な別内容」の体制について、二参照で測った実測値は存在しません。**——**清潔な二参照の値は、変種の 57.9% だけです。**
**ただし参照を増やせば値は下がるだけなので、一参照の値が上界になります。**

> **二つの体制**——**別内容 ≦ 約10%** ／ **変種 57.9%**。**間が広く空いています。**

### 再現

```python
import io, re, unicodedata
def nz(s): return re.sub(r'\s', '', unicodedata.normalize('NFKC', s))
def g(s, n=5):
    z = nz(s); return {z[i:i+n] for i in range(max(0, len(z)-n+1))}
# 全重複      : len(g(X) & g(O)) / len(g(X))
# O 固有（二参照）: len((g(X) & g(O)) - (g(Onull) | g(Lneg))) / len(g(X))
```

## 3. 選択肢

| 案 | 測る量 | 上限 | 意味するところ |
