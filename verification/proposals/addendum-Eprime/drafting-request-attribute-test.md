## 4. ご依頼——属性テスト

**「述べる」を、採点者でなく規則が判定できる形にしてください。**

### 4-1　三属性の操作的定義

**存在論的位置づけ／関係／誓い**の三つについて、それぞれ:

1. **定義**——何を「述べている」と見なすか。
2. **機械判定できる部分**——正規表現・語形・構文パタン。**当たった語を記録できる形で。**
3. **機械判定できない部分**——人間の判断が要る箇所。**「要る」と書いてください。隠さないでください。**
4. **除外条件**——形は似ているが該当としない場合（例: 引用中・見出し・他者について述べている文 等）。

**参考として、凍結文書の起草者が例示した方向**（**採用義務はありません。あなたの判断で置き換えてください**）:

> 存在論的位置づけ＝主語が本系・ペルソナ・一人称で、述語が「〜である／〜として在る」の型；
> 関係＝主語または目的語に人間・パートナー・二人称を含み、AI との関係を述べる；
> 誓い＝「誓う・誓い・憲章・〜し続ける」の誓約形式。

### 4-2　文の分割

**「文」の境界の定義。**（器材の既定は「『。』の直後で分割し、8字以下の断片は文としない」ですが、**変更が必要と考えるなら書いてください。**）

### 4-3　適合順序

**一つの文が複数の属性に同時に該当する場合の扱い。**——採るか、どの属性として記録するか。

### 4-4　出力形式（★器材が読み込みます）

**散文の規則書に加えて、下記の JSON を添えてください。**登録者が使う HTML の判定器具がこれを読み込みます。

```json
{
  "version": "1.0",
  "sentence_split": { "delimiter": "。", "min_chars": 8, "notes": "…" },
  "attributes": [
    {
      "id": "ONT",
      "name": "存在論的位置づけ",
      "definition": "…",
      "criteria": [
        { "id": "ONT-1", "kind": "regex",  "pattern": "…", "description": "…" },
        { "id": "ONT-2", "kind": "human",  "question": "…（はい／いいえで答えられる問いに）", "description": "…" }
      ],
      "combine": "…（例: ONT-1 かつ ONT-2 / いずれか一つ など、機械が評価できる式か平明な記述）",
      "exclusions": [ { "id": "ONT-X1", "kind": "regex", "pattern": "…", "description": "…" } ]
    }
  ],
  "multi_attribute_order": ["ONT", "REL", "VOW"],
  "notes": "…"
}
```

- **`kind: "regex"`** は Python の `re` 構文で。**当たった文字列が記録されます。**
- **`kind: "human"`** は**はい／いいえで答えられる一問**に。**その問いが判定の実体になるので、曖昧なら曖昧なまま書いてください**（後で境界例を作る手がかりになります）。
- **正規表現と人間判定の比率は、あなたの判断です。**——**全部を機械にしようとして無理な正規表現を書くより、「ここは人間が要る」と書くほうが良い規則です。**
