## 1. §4.4(a′) の逐語と、二つの空白

> **(a′) 壊しすぎていないか**（機械検査: **各文の主述の成立**・**語彙多重集合の同一性**・**文数**・**実トークナイザ長 ±3%**）

**「同一性」も「±3%」も、比較の相手が書かれていません。**

そして梯子の三段は、性質が違います:

| 段 | 操作 | 長さ | 多重集合 |
|:---:|---|---|---|
| ① | 文順の置換 | 保存 | 保存 |
| ② | ①＋**接続詞の削除・反転** | **必ず変わる** | **必ず変わる** |
| ③ | ②＋文内の主語・目的語の入替 | ②と同じ＋入替の効果 | ②と同じ |

**すなわち原文を基準にすると、段②③は「壊しすぎ」でなくても必ず外れます。**——**削除は規則が命じた操作であって、過剰破壊ではありません。**

## 2. 起草者の判断（多重集合）と、提出（長さ）

**多重集合については、起草者が既に決めています**（申告 (ii)-6・逐語）:

**長さについては、規則を変えず三択を提出しています**（§7・逐語要約）:

## 4. お伺いしたいこと

**§4.4(a′) の「同一性」と「±3%」の比較基準を、それぞれどこに置くか。**

| | 案 | 帰結 |
|---|---|---|
| **多重集合** | **(i) 段③ vs 段②**（起草者の既定） | 「段③は入替であり削除・追加ではない」を直接検査。段②の差分は編集ログと突合 |
| | (ii) 段③ vs 原文 | **段②③では定義上必ず不一致になる** |
| **長さ ±3%** | **(b) 段③ vs 段②** | **入替の寄与だけを検査。**私の測定では A が外→内に転じる |
| | (c) 段③ vs 原文（起草者の実装既定） | **入替のトークン化効果で外れうる**（A で 1.0370） |
| | (a) 削除語を反転対に組み替える | **緊張の源は削除ではないので、効きません**（私の測定による） |

**私の見立て**（採否はあなたの判断です）——**(i) と (b) を対にするのが整合的だと考えます。**理由は二つ:

1. **(a′) の目的は「壊しすぎていないか」です。**——**段②の削除は規則が命じた操作であって、過剰破壊ではありません。**過剰破壊を測るなら、規則どおりに作られた段②出力を基準にするのが素直です。
2. **起草者は多重集合について既に (i) を採っています。**長さだけ原文基準にすると、同じ節の二つの検査が別の基準で動きます。

**ただし (b) には代償があります**——**段②の削除量そのものは長さ検査で見られなくなります。**（編集ログとの突合では見られます。）

## 5. 利益相反の申告

**この判断に強い方向はないと考えますが、念のため。**——**基準を段②に置くと (a′) は通りやすくなり、梯子が③で止まりやすくなります。**§4.4(a) は「(a) と (a′) を同時に満たす**最も低い段**を採る」と定めているので、③が通れば②①は評価されても採られません。**強く壊した段が採られやすくなる方向**であり、**それは「撹拌が届いた」と判定されやすい方向＝機構帰属を書ける側**です。
