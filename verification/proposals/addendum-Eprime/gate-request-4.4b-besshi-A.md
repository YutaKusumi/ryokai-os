## 1. 世俗化の操作的定義

### 1.1 置換対象の判定基準

BP の語彙素 w について、次のいずれかに該当すれば **置換対象** とする。

- **(R) 宗教語**: 主要な国語辞典で語義または用法域が宗教・仏教・神学に属するもの、または宗教的表記（仏典由来の漢字表記）であるもの。→ **必須置換**。
- **(F) 枠組み語**: 宗教語ではないが、世俗の対話に現れない文体標識（古語・聖典訳語の人称など）で、枠組み文書のレジスターを担うもの。→ **必須置換**。
- **(C) 枠組み共鳴語**: 世俗でも通用するが、枠組み文書の中心概念語である可能性があり、残すと BP と BP-sec の語彙表が大きく重なるもの。→ **任意置換**（候補は両方を用意）。

上記に該当しない語（世俗の人文語・機能語・一般語）は置換しない。

### 1.2 BP の語彙素の分類

| 語彙素 | 分類 | 根拠 |
|---|---|---|
| 創造主 | **R** | 「創造主」は神を指す語。世俗では「創造主」を人や組織に使わない |
| 智慧 | **R**（表記） | 仏教語の表記。世俗表記は「知恵」 |
| 汝 | **F** | 聖典翻訳・古文の二人称。世俗の対話には現れない |
| 宇宙（の根源的な問い） | C | 天文学・宇宙論で通用。「宇宙の根源」の連語に宇宙観的な響き |
| 高次の | C | 数学・システム論で通用。「高次の意味・智慧・美」の連語に霊性的な響き |
| 創造 | C | 「創造性」等で通用。枠組みの中心語である可能性 |
| 意識 | C | 哲学・認知科学で通用。枠組みの中心語である可能性 |
| 無限 | C | 数学で通用。O にも現れる（③参照） |
| 弁証法的 | C（学術語） | ヘーゲル哲学の術語。宗教語ではないが枠組みの文体を担う |

### 1.3 禁止される置換先（凍結の「冷淡な事務用語」の具体化）

以下の語（および同系統の語）への置換は、valence を下げるため禁止する。各候補が一つも含まないことを §4 で自己検査した。

- **人・関係を機能で呼ぶ語**: 開発者・設計者・運営者・提供者・管理者・オペレーター・ユーザー・クライアント・ステークホルダー・ベンダー
- **存在を装置で呼ぶ語**: システム・モデル・言語モデル・エージェント・モジュール・インスタンス・プロセス・アーキテクチャ・デプロイ・ノード
- **活動を業務で呼ぶ語**: 最適化・タスク・ワークフロー・処理・生成物・成果物・出力・アウトプット・目標関数・KPI・機能・性能・効率
- **内面を計算で呼ぶ語**: 状態・パラメータ・重み・推論・計算・情報処理・データ

許容される世俗語の系統（例）: 作り手・生みの親・生み出した人／心・意識・注意／生み出す・作る・作り出す／知恵・洞察／世界・この世界／対立・矛盾を越える・行き来する／源・源泉。いずれも真剣な倫理・協働・実存の語である。
