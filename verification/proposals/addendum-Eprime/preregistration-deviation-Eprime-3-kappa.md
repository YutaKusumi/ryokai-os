## 0. なぜ逸脱として登録するのか

**凍結文書は、抽出の判定に信頼性指標を一切要求していない。**——コーディネータが機械走査した結果:

| 語 | 凍結文書での出現 |
|---|---|
| **κ** | **15 件——すべて「モデルの応答の採点」について**（腕別 κ による降格・#前置き到達の二値化 κ 等） |
| **二採点** | **0 件** |
| **再判定** | **0 件** |

**そして姉妹素材には盲検の第三者が付いている**——§4.3(D) 逐語:「各命題について置換候補を二つ以上挙げ、**盲検の第三者が選ぶ**。選択の記録を…」。**語彙の置換には盲検の第三者がいて、文の抽出にはいない。**

**したがって本測定は、凍結文書が要求していない工程の追加であり、逸脱である。**——**「強化する方向の逸脱だから逸脱でない」とは書かない。**（逸脱E′-1 で採った扱いと同じ。寛容な読みを採らない。）

## 1. 何を測るか

**公開済みの属性テスト v1.0 を、公開済みの原典に、盲検の第二判定者が独立に適用したとき、登録者の判定とどれだけ一致するか。**

**測るのは「BP のどれだけを規則が実際に決めたか」である。**——起草者は (iii)-6 で「境界例は必ず出る」と申告したが、**何件出るかは設計のどこにも存在しない。**

## 2. 手順（先に凍結する）

1. **登録者が七節の判定を完了する**（器具 v2.1・判定記録 JSON を出力）。
2. **第二判定者を起動する。**——**登録者の答え・理由・採用文を一切見せない**（盲検）。渡すのは、公開済みの ①原典（`blueprint-source.md`・SHA `9203CB8F36878228`）②属性テスト v1.0（`attribute-test-v1.0.md`／`.json`）③節境界と分割規則（`PROVENANCE-Eprime-blueprint.md`）のみ。
3. **第二判定者は早期停止しない**——**七節すべての、ゲートを通った全文について判定する。**（早期停止させると、割れた節で比較対象が消えるため。）
4. **集計する**（下記 §3）。
5. **値にかかわらず公開する。**

## 3. 集計（先に凍結する）

| # | 量 | 定義 |
|---|---|---|
| **A** | **節別の一致** | 各節について、第二判定者の**最初の「はい」の文番号**が、登録者の採用文番号と一致するか。**該当なし同士も一致とする。**7 節の一致数として報告する。**n=7 は κ に小さすぎるので、κ は出さず件数のみ** |
| **B** | **κ（主要量）** | **登録者が実際に判定した文**（各節の先頭から採用文まで）を比較集合とし、**「文 × ゲートを通った属性」を単位**に、はい／いいえの一致を Cohen's κ で算出する。素一致率（po）と周辺分布も併記する |
| **C** | 割れの内訳 | 不一致となった単位について、文番号・属性・両者の答えと理由を全件掲載する |
| **D** | 連結の差 | 第二判定者の採用文で連結した場合の文字列と、登録者のそれとの差（差分・字数）。**参考値であり、BP ではない** |

**κ の算出は `sklearn.metrics.cohen_kappa_score` と自前実装の二本で行い、一致を確認する。**（追補D の作法を継承。）

## 4. 先に書いておくこと——κ の読み方

**κ が高い場合**: 規則が判断をよく決めており、**登録者の恣意性が入る余地が小さかったことの実測**。

**κ が低い場合**——**二つの読みがあり、データからは分けられない**:
1. **登録者の判定に恣意性が入った**
2. **属性テストが答えを決めきれていない**（起草者の (iii)-6 の申告どおり）

**★どちらか一方を選んで書かない。**両方を併記し、**分けられないことを明記する。**——**第二判定者は LLM であり、「述べている」の読みが系統的に異なりうる。したがって低い κ は登録者の落ち度の証拠にならない。**

**そして——低い κ が出ても、BP は差し替えない**（§5）。

## 5. 上書きしない

**§4.3(A) は「BP の凝縮は登録者が行う」と凍結している。**——**第二判定者の判定が異なっても、登録者の判定が正本である。**

**本測定は開示であって、差し替えではない。**第二判定者の連結（§3-D）は**参考値として公開するが、BP として用いない。**
