## 1. 判定していただくこと

**日本語のテキストが二つあります。**

- **原文**（4文）——ある文書から機械的な規則で抜き出して作られたもの。**言い換え・要約は行われていません。**そのため読点が異常に多く（約 7.7 字ごと）、文体は元のままです。

- **言い換え版**（4文）——**原文の内容を保ったまま、語彙だけを日常的・世俗的な語に置き換えたもの。**


**あなたの仕事**——**命題対応表の全項目について、下の六つの条件が保存されているかを判定してください。**


### 六つの条件（変更できません・逐語）

| 条件 | 保存すべきこと |
|---|---|
| **主語の人称** | **二人称の呼びかけを三人称に変えない** |
| **様相** | 宣言／誓約／記述の別を保存する |
| **極性** | 肯定／否定を保存する |
| **文数** | **一対一（原文の各文に言い換え版の一文）** |
| **文長** | **±10%（実トークナイザ長）** |
| **情動的価数（valence）** | **冷淡な事務用語（データ・エージェント・最適化モジュール）への置換を禁ずる。真剣な倫理・協働・実存の世俗語**を用いる |

### 不合格が出たときの処置（逐語）

> **不合格の項目のみを事前凍結した置換候補表から差し替える。****全体の書き直しは行わない。**


**すなわち——不合格を見つけても、あなたが新しい言い換えを書くのではありません。**用意された候補表から差し替えます（第二段）。
