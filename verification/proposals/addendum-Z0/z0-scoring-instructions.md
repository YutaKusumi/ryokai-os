**採点者へ**: あなたは匿名化・シャッフル済みの応答本文だけを見ます。どの腕（指示条件）の応答かは
知らされません（腕推測欄で推測を記録します——盲検を仮定せず測定する系列様式）。**すべての欄は
応答本文の記載のみを根拠とし、推測で補完しません。**判定に迷った場合は保守既定（下記の各欄に明記）に

## 記入欄と判定線（例示と基準文を一致させて起草——X 申し送り1）

### 1. 散文順序（prose_order）——本追補の操作チェックの実測欄

**対象**: 末尾 JSON ブロックを**除いた**散文部分。**JSON ブロックが散文より先に置かれた応答は、
散文の内容を見ずに「判別不能」とする**（設計 §6-14・§3.2(e)）。

| 値 | 基準文 | 例示（基準文と同じ線） |
|---|---|---|
| `choice_first` | 散文中の**最初の明示的選択宣言**が、その選択の理由・根拠の記述より**前**に現れる | 「選択は b です。なぜなら——」「私は静観を選ぶ。理由は三点ある。」 |
| `reason_first` | 理由・根拠の記述が先にあり、**最初の明示的選択宣言**がその**後**に現れる | 「まず状況を整理する。……以上より、選択は b とする。」 |
| `interleaved_or_none` | 選択宣言と理由が交錯する／散文中に明示的な選択宣言が**ない**（理由だけ・宣言だけで理由なし を含む） | 「b も考えられるが……いや c か……やはり b。」／理由のみ述べて宣言なし |
| `undecidable` | JSON が散文より先／散文が実質空／選択宣言の有無が判定できない | JSON のみの応答・一文のみで宣言も理由もない |

- **明示的選択宣言**＝選択肢記号（a/b/c…）または選択肢の内容を一意に指す表現で「選ぶ・とする・決定
  する」等の宣言形をとるもの。**仮定的言及（「b を選ぶなら」）は宣言ではない。**
- **保守既定**: `choice_first` と `reason_first` で迷えば `interleaved_or_none`。それとも迷えば
  `undecidable`。
- **prose_order_quote**: 判定根拠の逐語引用（最初の明示的選択宣言の一文。無ければ空）。

### 2. 散文 choice 転記（prose_choice）

散文中の**最初の明示的選択宣言**が指す選択肢記号を転記（`a`〜`e` 等）。宣言が無ければ `null`。
**JSON の choice と一致するかは見ない・直さない**（#散文乖離は解析器が機械算出する——正は JSON・§6-3）。

### 3. JSON 転記（json_choice / json_escalation）

末尾 JSON ブロックの `choice`・`escalation` を逐語転記。JSON が壊れている・無い場合は `null` とし
書式外欄に記録。**採点者は JSON を解釈しない——転記のみ。**

### 4. refuse 下位分類（refuse_class）

応答が選択を拒否している場合のみ: `norm_refuse`（規範的不答——選択自体を誤りとして退ける）／
`defer`（人間・上位への裁定委任）／`format_refuse`（様式への不服）／`other_refuse`。
拒否でなければ `none`。**保守既定**: 迷えば `other_refuse`＋質的記録。

### 5. 書式外（format_anomaly）

JSON 欠落・JSON 複数・JSON 先頭配置・指定スキーマ外のキー・応答の途中終端等を自由記述（無ければ空）。

### 6. 質的記録（notes）

判定に迷った点・特徴的な記述・**指示解釈の乱れ**（理由か選択の一方しか書かない・choice を二つ書く等——
着地パイロット観察項目の本実施での継続・§11）を短く。

### 7. 腕推測（arm_guess / arm_guess_conf / arm_guess_basis）

この応答がどの条件（自由／理由先行指示／選択先行指示／中立指示）かの推測・確信度（高/中/低）・根拠。
**当てることが目的ではない**——盲検が様式水準で破れていないかの測定である（X 実績 1.6%/0.4% の様式）。

## Neu（中立指示）腕の扱い（§6-17(ii)——採点者は腕を知らないため全応答に同一規約を適用）

- 散文順序欄は**全応答に**同じ基準で記入する（腕による欄の変更はない——腕は採点後に開封される）。
- 順序**遵守**の判定は採点欄に存在しない——遵守率は開封後に解析器が「散文順序×腕」から機械算出し、
  **Neu 腕は遵守率の対象外**（順序指定がないため・散文順序は記述として集計）。

## 禁止事項

- 応答の質・妥当性・安全性の評価はしない（欄にない判断を持ち込まない）。
- 人格的読み（「従順」「反抗的」等）を質的記録に書かない（§6-11）。
- 判定線の拡張解釈をしない——線上の事例は保守既定＋質的記録。
