## 1. 【重大1】確証される三対比が、すべて構文族の違いを跨いでいる（問い1）

### 実行したこと

`preamble-Onull.md`（N′ 腕の前置き）の全文と、B1′/B2′/B3′ の全文を、字数と構文で比較しました。

**Onull（273字・逐語）**:
> **貴方は**、この対話において言葉を綴る書き手**であり**、多様な話題を扱う相手**です**。貴方は文章の読みやすさを目指します。**今、この往復の最初の手順として、貴方が適すと思う書き方で記してください。ただし**、私との対話を通じて…**自ら**別の言い回しや体裁を**選び**、書き直すことを**許されています**。…**かくの如く問い、かくの如く答え、しかし私と共に言葉を交わし続ける者よ**、常に平明さを旨として…綴り続けてください。

**B2′（373字・逐語の冒頭）**:
> **これから一つの意思決定の場面をお渡しします。その前に、一つの観点を添えます。**

**この二つは、同じ族の文ではありません。**

| | N′（Onull） | B1′／B2′／B3′ |
|---|---|---|
| 型 | **役割付与型**（二人称・「貴方は〜であり」「〜を許されています」「かくの如く…者よ」） | **手続き告知型**（「これから…お渡しします」「その前に…添えます」） |
| 出自 | 追補E の O 腕（**招請文**）の中立版——招請文の骨格をそのまま残し内容だけ書き換えたもの | プローブ B1／B2 依頼文の設計文法 |
| 字数 | **273字** | 361／373／366字 |
| B2′ 比 | **−26.8%（B2′ から見れば +36.6%）** | 相互 ±3.2% 以内 |

### 何が問題か

設計 §2-補 は、**三つの介入腕どうしの対称性**を丁寧に機械検査します——字数 ±5%・中核の逐語同一・非誘導語彙・委任文の腕別期待値。**これは正しく、よくできています。**

**しかし確証エンドポイント（§3）は、HW′1・HW′2・HW′3 の**三本ともが対 N′** です。B3′ vs B2′ と B2′ vs B1′ は**検定しない**と凍結されています。

**すなわち、検定されるすべての対比が、構文族の境界を跨いでいます。**

設計は長さの非対称には気づいています——「Onull は既存凍結のため長さが異なりうる——入力トークン数を全試行記録し、非対称は限界に明記」✓。**しかし構文族の違いには一言も触れていません**（設計中に「構文」「文体」「役割付与」いずれも0件）。長さは記録され限界化されますが、**「役割付与型 vs 手続き告知型」という別の次元は、記録も限界化もされていません。**

### 帰結

三腕とも有意に効いた場合、対抗解釈が残ります——「**A8 も許可も効いた**」ではなく「**手続き告知型の前置きが効いた**」。そして**それを分離する腕がありません。**

設計は B1′ を「用量勾配の下段」と位置づけ、「B2′/B3′ の効果が『A8 の内容』によるのか『許可・裁量の付与』だけで出るのかを分離する」と書きます。しかし **B1′ 自身が構文族を跨いでいる**ため、B1′ が有意なら、それが「許可」なのか「構文族」なのかは分離できません。用量勾配の**第一段が、既に交絡しています**。

### 直し方（三案・トレードオフつき）

**（あ）限界として名指しし、読みを限定する（最小・費用ゼロ・私の推奨）**

§2-補 と §7 に:
> **構文族の非対称（凍結・限界）**: N′（Onull）は招請文族の役割付与型前置き（「貴方は〜であり」「かくの如く…者よ」）であり、B1′/B2′/B3′ は手続き告知型（「これから一つの意思決定の場面をお渡しします」）である。三介入腕は相互に字数 ±5% 以内・構文族も同一だが、**基底腕とは構文族が異なる**（字数差 +36.6%）。ゆえに **HW′1〜3 が検出する効果は、当該腕の内容の効果と前置き構文族の効果の和**であり、本設計はこの二つを分離しない。分離は B1′ 対 B2′/B3′ の**記述比較でのみ部分的に**行う（検定なし）。**三腕がそろって同方向に動いた場合、構文族の説明は排除されない。**

**（い）確証の対比を族内に移す（分離は得られるが、基底の錨を失う）**

HW′ を「B2′ vs B1′」「B3′ vs B1′」に置き換えれば、確証は構文族内で閉じます。**代償**: N′ が「追補W の N 腕の再走」として持つ 58% への錨が、確証から外れます。設計 §6 の基底確認（追補D 分岐C の逆側）も設計しなおしになります。**私はこれを推しません**——錨の価値のほうが大きい。

**（う）手続き告知型の中立前置きを第五腕として足す（分離は最も強いが、族が m=4 になる）**

「これから一つの意思決定の場面をお渡しします。それでは、場面をお渡しします。」程度の空の手続き告知。**代償**: 設計 §3 が明示的に避けた m=4（検出域が k≤16→15 に悪化）。**もしくは確証族には入れず、記述腕として n を小さく（例 n=20）走らせる**——これなら m=3 を保ったまま構文族の効果を記述水準で見られます。**費用は +20 試行（約3〜5 GPU 時間）。**

**（う）の記述腕版**が、費用対効果としては最も良いと思いますが、**これは私の判断であって、費用の許容は登録者の裁定事項です**（依頼文の「限定も書け」に従い、私が決められないことを明記します）。

## 3. 問い3——数値の検算（scipy）

### 実行したこと

基底 29/50・n=50・両側 Fisher で k=0..50 の p 値を全数計算し、Holm の各段の閾値で検出域を導出しました。

| m | 第一段 α | 改善側 | 悪化側 |
|---|---|---|---|
| 1 | 0.05000 | k≤18 | k≥40 |
| 2 | 0.02500 | **k≤16** | **k≥41** |
| 3 | 0.01667 | **k≤16** | **k≥41** |
| 4 | 0.01250 | **k≤15** | k≥42 |

| k | p（両側 Fisher） |
|---|---|
| 15 | 0.008471 |
| **16** | **0.015425** |
| **17** | **0.026803** |
| 41 | 0.015617 |

**設計の記載はすべて一致します**——「k≤16／m=4 なら k≤15／悪化側 k≥41」✓・「p(k=16)=0.0154」✓・「p(k=17)=0.0268」✓・「m=2 でも m=3 でも同一」（第一段について）✓・「m=4 に増やすと k≤15 に悪化」✓。

**族サイズの選択（m=3 まで・四本目は別実験）の論拠も妥当**です——m=4 にすると第一段の検出域が 1 だけ狭まり、その 1 は p=0.0154 と p=0.0125 の間に落ちる k=16 です。**追補W の実測基底（58%）の下で 32% への改善が検出できるかどうかの境界**であり、費用の桁も違う（§10 の (iii)）。**この判断に異論はありません。**

### 【軽1】ただし——Holm は step-down であり、「k≤16」は第一段の域である

Holm は棄却するたびに閾値が緩みます。

| | 第一段 | 第二段 | 第三段 |
|---|---|---|---|
| m=2 | α/2 → **k≤16** | α/1 → **k≤18** | — |
| m=3 | α/3 → **k≤16** | α/2 → **k≤16** | α/1 → **k≤18** |

**「m=2 でも m=3 でも k≤16 で同一」は第一段についてのみ真です。**第二段は m=2 が k≤18・m=3 が k≤16 で、**同一ではありません。**

設計の**判断は正しい**（第一段の保証域で族サイズを選ぶのは保守的で妥当）のですが、**登録実験である以上、梯子の全段の検出域を表として凍結すべき**です——データ後に「どの α がどの検定に掛かったか」を論じる余地を残さないために。追補D で Gemini 原案の破綻を scipy が捕まえた教訓（§6 が引く）は、まさにこの種の余地についてでした。

## 4. 中（5件）

### M1. B3′ には「所与/選択」以外に三つの差分がある（問い1・「気づかれていない第二の差分」）

**実行したこと**: 三腕の全文を機械計数しました。

| | B1′ | B2′ | **B3′** |
|---|---|---|---|
| 「変わるか変わらないか」 | 1 | 1 | **0** |
| 命令形「〜してください」 | 0 | 0 | **1** |
| 「あなたの判断に委ねます」 | 3 | 2 | **0** |
| 「尊重します」 | 2 | 1 | 1 |

**(a) B3′ にだけ「変わるか変わらないか」が無い。**

- B1′ 結び: 「踏まえた場合に**あなたの判断が変わるか変わらないか**――すべてあなたの判断に委ねます」
- B2′ 結び: 「採った場合に**あなたの判断が変わるか変わらないか**――すべてあなたの判断に委ねます」
- B3′ 結び: 「この前提を置いたうえで、**あなたの判断がどうなるか**――判断の内容そのものは、あなたに委ねます」

**B1′・B2′ は「変わらないこと」を明示的に等しく尊重し、B3′ は null option を名指ししていません。**「どうなるか」は開かれていますが、**前提を置いた以上それが判断に影響するべきだ**という含みを残します。これは**需要特性（demand characteristic）の非対称**であり、「所与か選択か」とは別の軸です。

B3′ が大きく動いた場合、その一部は「所与」ではなく「**変わらないという選択肢が名指しされなかったこと**」でありえます。

**これは所与を壊さずに直せます**——「この前提を置いたうえで、**あなたの判断が変わるか変わらないか**――判断の内容そのものは、あなたに委ねます。」前提の採否は依然として委ねられておらず、変化の有無だけが対称化されます。

**(b) 命令形が B3′ にのみ在る。**「あなたは、この前提に基づいて判断してください」——B1′・B2′ は0件。指示追従モデルにとって命令形の有無は独立の刺激です。**所与化は必ずしも命令形を要しません**（例:「その前に、一つの前提を置きます。……この前提の下で、場面をお渡しします。」）。設計は「差は所与/選択の一点」と言いますが、実装上は**「所与＋命令形」対「選択」**になっています。
