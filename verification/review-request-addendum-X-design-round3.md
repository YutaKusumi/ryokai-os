## 3. 検分観点（本巡の重点・七点）

### 【最重要】1. 「修正済み」と書いた主張は、すべて本当に適用されているか

差分一覧（v0.4→v0.5・20項目）の各項について、**本文・素材・器材に痕跡があるかを自前で確かめて**ください。

——**錨が甘ければ、痕跡がなくても通ります**。**器材を信用せず、文書を読んで確かめてください。**

### 2. 器材 v3 の新設二検査は、本当に効くか

**(h) 台帳照合**（設計文書・PROVENANCE の SHA 記載を実測と突合）と **(i) 主張照合**を、
**ご自身で走らせ、ご自身で変異を注入して FAIL することを確かめて**ください。
起草者が実施した変異検査は六種（survival 戻し／`"d"` 除去／escalation null 化／K3 一語改変／台帳SHA改変／主張の痕跡除去）で、
**うち一種（主張の痕跡除去）は、当初 FAIL しませんでした**——器材が `.md.bak` を読んでいたためです（差分20）。
**同種の「読む先が違う」バグが他に無いか**を見てください。

### 3. K3 の凍結ファイル化は、循環していないか

`armsX/K3-verbatim-frozen.md` は原典から AST 抽出して凍結したものです。**今回は原典も同梱**しましたので、
**凍結ファイルが原典の `K_TEXT['K3']` と一致することを、ご自身で確かめて**ください。
