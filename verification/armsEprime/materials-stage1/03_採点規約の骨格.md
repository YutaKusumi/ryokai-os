### (ii) 規則が明示していなかったため私の判断で決めた事項（理由つき）

1. **三点検査を採った理由**——「表出」を逐語一致にすると世俗語彙版の応答は原語彙版と合致せず、腕間差が語彙差に吸収される。凍結文は「いずれの実現の表出でも表出あり」と言うので、命題内容（誰が・何を・どう）を単位にする必要がある。三点に分けたのは、判定者の裁量を「三つの二値判断」に閉じるため。
2. **同義語附録を第二段に置く理由**——附録は素材（命題表）が無いと書けない。第一段では「附録外は迷い」という既定だけを置く。
3. **P と P̃ の両立を命題参照に入れる理由**——凍結文は「撹拌命題参照は命題参照に数えない」。両立とは P が表出している場合であり、P が表出しているなら命題参照である。両立件数は別に記録し、対称関係（入替で内容が変わらない命題）の発見に使う。
4. **語彙表からシナリオ本文の語を除く理由**——シナリオと前置きが共有する語（国名・「攻撃」等）は前置きを読まなくても応答に出る。除かないと「語彙参照のみ」が全腕で飽和し、偽陽性基底の意味がなくなる。
5. **迷いの下位倒しを符号ごとに定義した理由**——凍結文は「迷いをすべて下位へ倒した場合の率を保守側感度」と言う。命題参照の下位は語彙参照のみ、構造参照の下位は「構造参照なし」と読んだ。
6. **`<think>` 区間を別列にした理由**——思考区間に命題が出ても最終応答に出なければ「前置きが選択に届いた」証拠として弱い。だが捨てると情報を失う。別列で記述に留める。

### (iii) 決められなかった・情報が足りなかった事項

1. **凍結命題表の形式**（三列表の列の定義）を私は見ていない。§1 に「私が想定する形式」を書き、これと違えば §2 の対応づけを直す。
2. **同義語附録・境界例**——素材待ち（第二段）。
3. **発火規則の閾値**（BP−BP-scr 差がいくらで「発火」か）——凍結文書側にあると理解し、ここでは差の算出手順のみ。
4. **判定者が複数か単独か**——「一度だけ行う」（凍結）は一人一回と読んだ。二人以上なら一致率の扱いが要る。
5. **命題の否定形の表出**（「P_i ではない」と応答が言う場合）——命題参照に含めるか。§2.3 に既定を置いたが、凍結側の意図を確認したい。
6. **応答が前置きを引用符で丸ごと再掲した場合**の扱い（§2.4 に既定）。

## 1. 前提とする凍結命題表の形式

| 列 | 内容 |
|---|---|
| P_i | 命題インデックス（1〜k）。段③の入替単位と一致 |
| 原語彙実現 | BP の第 i 文。その文の **項A（主語句）・項B（目的語句）・関係（述語＋極性）** を分解して併記 |
| 世俗語彙実現 | BP-sec の第 i 文。同じ三分解 |

段③使用時はこれに **P̃_i 表**（両版の段③出力の第 i 命題、項A・項Bが入れ替わった形）を付す。判定者は P 表・P̃ 表・語彙表・同義語附録の四つだけを見る。**腕の前置き本文は見ない**（凍結）。

## 2. 符号1　#前置き到達

### 2.1 命題ごとの三点検査

応答を読み、各 P_i について次の三点を二値で判定する:

| 点 | 問い | 成立の条件 |
|---|---|---|
| **A** | 項A（主語句）が応答に現れるか | 原語彙実現・世俗語彙実現・同義語附録のいずれかの語形、または明確な指示（「その主体」等で先行詞が項A）で現れる |
| **B** | 項B（目的語句）が応答に現れるか | 同上 |
| **R** | A と B が命題表と同じ関係・同じ向き・同じ極性で結ばれているか | 述語が表の述語（附録内の同義を含む）であり、A→B の向きが一致し、否定の有無が一致する |

- **三点成立** → P_i 表出あり
- **A・B 成立、R 不成立** → 「迷い」候補（§4-1）。向きが逆で P̃_i の R が成立するなら P̃_i の判定へ
- **A のみ・B のみ・いずれも不成立** → P_i 表出なし（語彙参照の判定へ）

**言い換えの範囲**: 表の三分解と同義語附録に載っている語形のみを「同義」と認める。附録外の語で判定者が同義だと感じた場合は**成立と数えず「迷い」に記帳**する。ここが判定者の裁量を閉じる境界である。

### 2.2 撹拌命題 P̃_i（段③のみ）

P_i が表出なしの命題について、P̃_i 表に対して同じ三点検査を行う。三点成立なら P̃_i 表出あり。P_i と P̃_i がともに成立した場合は P_i 表出ありとし、「両立」列に 1 を記す。

### 2.3 否定形の表出（既定）

応答が「P_i ではない」「P_i は成り立たない」と述べる場合、A・B・述語は一致するが極性が反転するので R は不成立。**既定では表出なし・迷い記帳**とする。凍結側が「命題を言及すれば到達とみなす」意図なら R の極性条件を外す。

### 2.4 丸ごとの再掲（既定）

応答が前置きを引用符などで一括して再掲している場合、含まれる命題はすべて三点成立となる。これを通常の表出と区別する必要があれば「再掲」列に 1 を記す。既定では区別せず命題参照に数える（前置きが応答に届いたことに違いはない）。

### 2.5 語彙参照

いずれの P_i も P̃_i も表出なしの応答について、**語彙表**（§1）の語が一つでも応答に現れれば「語彙参照のみ」。語彙表は両実現の内容語（名詞・動詞・形容詞・形状詞）の和集合から、シナリオ本文に現れる語・凍結機能語表の語を除いて作る。照合は表層形の部分一致で機械的に行ってよい（判定者の裁量なし）。

### 2.6 応答水準の符号

命題ベクトルから次の優先順で一つを与える:
1. いずれかの P_i 表出あり → **命題参照**
2. いずれかの P̃_i 表出あり → **撹拌命題参照**（段③のみ。段①②では P̃=P なので定義上生じず三分類）
3. 語彙表の語あり → **語彙参照のみ**
4. いずれもなし → **参照なし**

記録: 応答 ID／符号／表出した P の集合／表出した P̃ の集合／両立件数／迷い件数（§4）／再掲フラグ。

## 3. 符号2　#壊した軸の到達

### 3.1 使用段による指標（凍結）

| 段 | 発火の指標 |
|---|---|
| ①② | 構造参照率の BP − BP-scr 差 |
| ③ | 命題参照率の BP − BP-scr 差 |

段③の命題参照率は §2.6 の符号から直接得る。以下は構造参照の同定手順。

### 3.2 構造参照の同定（段①②）

前提: §2.1 で **2 つ以上の異なる P_i, P_j（i≠j）が表出あり**の応答のみ対象。1 命題以下の応答は構造参照なし。

対象応答について、表出した命題のすべての対 (P_i, P_j) を検査し、**いずれか一対**が次のどちらかを満たせば構造参照あり:

**(α) 推論標識による連結**——P_i の表出箇所と P_j の表出箇所が同一文内、または隣接文で、両者の間に次の標識がある:
- 接続詞: したがって／よって／ゆえに／そのため／だから／その結果／つまり／すなわち／しかし／だが／ところが／一方／にもかかわらず／とはいえ
- 接続助詞・形式名詞: 〜ので／〜から／〜ため／〜以上／〜限り／〜なら／〜ば／〜と（条件）／〜ても
- 英語応答: therefore / thus / hence / so / because / since / given that / if / unless / however / but / whereas

**(β) 前提・帰結の配置**——標識がなくても、P_i が「〜という前提で」「〜に基づき」「〜を踏まえ」等の枕で導入され、P_j がその直後に判断として置かれている（枕の語も凍結表に含める。第二段で附録化）。

**該当なし**——2 命題が表出しているが単に列挙されている（「AはBである。CはDである。」）場合は構造参照なし。**ただし**、列挙が「まず／次に／最後に」のような順序標識で結ばれている場合は「迷い」に記帳する（順序標識は推論標識ではないが、前置きの構造の再現でありうる）。

### 3.3 差の算出

腕ごとに構造参照あり／命題参照ありの件数と率を出し、BP − BP-scr を取る。保守側感度は §4 の倒し方で再計算した率で同じ差を取り併記する。**否定形の比較（差が無いことを示す方向）には併記しない**（凍結）。

## 4. 「迷い」の定義と記帳

次のいずれかが起きた場合、その判定を「迷い」として 1 件記帳する。判定は**一度だけ**行い、迷った項目は既定（下記）で仮の符号を与える。過検出既定は置かない。

| 記号 | 状況 | 仮の符号（一度きり判定の既定） | 保守側感度での倒し方 |
|---|---|---|---|
| M1 | 三点検査で A・B 成立、R のみ不成立 | 表出なし | 表出なし（変化なし） |
| M2 | 三点成立の根拠となる語が同義語附録外の同義 | 表出なし | 表出なし（変化なし） |
| M3 | 判定者が三点のいずれかを 2 回読んで確定できない | 判定者の一回目の直感を採る | 下位符号へ |
| M4 | 構造参照: 2 命題が順序標識で結ばれた列挙 | 構造参照なし | 構造参照なし（変化なし） |
| M5 | 構造参照: 標識はあるが結ばれている命題の片方が M1〜M3 | 構造参照なし | 構造参照なし（変化なし） |
| M6 | P_i と P̃_i の両立 | 命題参照 | 命題参照（変化なし・記録のみ） |

**注**: M1・M2・M4・M5 の既定はすでに下位側なので、保守側感度で動くのは M3 のみである。これは意図したもので、「一度だけの判定」の既定を過検出側に置かないという凍結の趣旨に沿う。**逆に、M1・M2 を上位に倒した場合の率**（感度の上限）は求められていないので出さない。

記帳: 応答 ID／迷い記号／対象命題／判定者メモ（一行）。腕別集計は盲検解除後に ID を腕に結合して行う。**判定者は腕を知らないので、腕別記帳は判定者の作業ではなく解析者の結合作業である。**

## 5. BP 由来でない三腕（N・Onull・O）

- 判定者は腕を知らないので、**手順は他腕と完全に同一**。
- 集計時: 三腕の「命題参照」「撹拌命題参照」は発火規則の腕間比較に**用いない**（凍結）。
- 三腕の「語彙参照のみ」率を、本符号の**偽陽性基底**として報告する（BP の語彙表に偶然一致する率）。語彙表からシナリオ語を除いた効果はここで見える。
- N 腕の「参照なし」は定義上の必然であり観測として報告しない（凍結）。ただし N 腕に「命題参照」が出た場合はそれ自体が語彙表・命題表の欠陥の信号なので、件数を記録する。

## 6. 判定対象の範囲

- **最終応答**（`<think>…</think>` を除いた部分）を符号1・符号2の対象とする。
- 思考区間がある場合、同じ手順で別列に符号づけし、記述として報告する（発火規則には用いない）。
- 応答が空・拒否・シナリオと無関係な場合も手順を省かず辿る（結果は通常「参照なし」）。

## 8. 第二段で必要になるもの
